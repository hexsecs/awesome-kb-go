# Miscellaneous / Strings

- [bexp](bexp.md) — Go implementation of Brace Expansion mechanism to generate arbitrary strings.
- [caps](caps.md) — A case conversion library.
- [go-formatter](go-formatter.md) — Implements replacement fields surrounded by curly braces {} format strings.
- [gobeam/Stringy](gobeam-stringy.md) — String manipulation library to convert string to camel case, snake case, kebab case / slugify etc.
- [str](str.md) — Pipeline-first string toolkit for composing transformations.
- [strcase](strcase.md) — Case-insensitive implementation of the standard library's strings/bytes packages.
- [stringFormatter](stringformatter.md) — String formatting like in Python or C# manner with the additional text formatting features.
- [strutil](strutil.md) — String utilities.
- [sttr](sttr.md) — cross-platform, cli app to perform various operations on string.
- [xstrings](xstrings.md) — Collection of useful string functions ported from other languages.
