# Data Structures and Algorithms / Text Analysis

- [bleve](bleve.md) — Modern text indexing library for go.
- [go-adaptive-radix-tree](go-adaptive-radix-tree.md) — Go implementation of Adaptive Radix Tree.
- [go-edlib](go-edlib.md) — Go string comparison and edit distance algorithms library (Levenshtein, LCS, Hamming, Damerau levenshtein, Jaro-Winkler, etc.) compatible with Unicode.
- [levenshtein](levenshtein.md) — Levenshtein distance and similarity metrics with customizable edit costs and Winkler-like bonus for common prefix.
- [levenshtein](levenshtein-2.md) — Implementation to calculate levenshtein distance in Go.
- [mspm](mspm.md) — Multi-String Pattern Matching Algorithm for information retrieval.
- [parsefields](parsefields.md) — Tools for parse JSON-like logs for collecting unique fields and events.
- [ptrie](ptrie.md) — An implementation of prefix tree.
- [radixtree](radixtree.md) — Adaptive radix tree (prefix-tree or compact-trie).
- [trie](trie.md) — Trie implementation in Go.
