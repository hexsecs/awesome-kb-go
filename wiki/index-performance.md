# Performance

- [ebpf-go](ebpf-go.md) — Provides utilities for loading, compiling, and debugging eBPF programs.
- [go-instrument](go-instrument.md) — Automatically add spans to all methods and functions.
- [go-perfstat](go-perfstat.md) — Lightweight performance statistics and execution time aggregation for Go.
- [jaeger](jaeger.md) — A distributed tracing system.
- [mm-go](mm-go.md) — Generic manual memory management for golang.
- [otelinji](otelinji.md) — OpenTelemetry auto-instrumentation tool for adding spans to functions.
- [pixie](pixie.md) — No instrumentation tracing for Golang applications via eBPF.
- [profile](profile.md) — Simple profiling support package for Go.
- [statsviz](statsviz.md) — Live visualization of your Go application runtime statistics.
- [tracer](tracer.md) — Simple, lightweight tracing.
