# Hardware

- [arduino-cli](arduino-cli.md) — Official Arduino CLI and library. Can run standalone, or be incorporated into larger Go projects.
- [emgo](emgo.md) — Go-like language for programming embedded systems (e.g. STM32 MCU).
- [ghw](ghw.md) — Golang hardware discovery/inspection library.
- [go-osc](go-osc.md) — Open Sound Control (OSC) bindings for Go.
- [go-rpio](go-rpio.md) — GPIO for Go, doesn't require cgo.
- [goroslib](goroslib.md) — Robot Operating System (ROS) library for Go.
- [joystick](joystick.md) — a polled API to read the state of an attached joystick.
- [moody](moody.md) — Hardware event personality daemon for macOS. Monitors USB, charger, lid, and other hardware events and responds with customizable personalities.
- [sysinfo](sysinfo.md) — A pure Go library providing Linux OS / kernel / hardware system information.
