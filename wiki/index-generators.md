# Generators

- [apispec](apispec.md) — Generate OpenAPI 3.1 specs from Go code without annotations, plus a browser UI to configure, preview, and explore the call graph.
- [convergen](convergen.md) — Feature rich type-to-type copy code generator.
- [copygen](copygen.md) — Generate any code based on Go types, including type-to-type converters (copy code) without reflection by default.
- [generis](generis.md) — Code generation tool providing generics, free-form macros, conditional compilation and HTML templating.
- [go-apispec](go-apispec.md) — Generate OpenAPI 3.1 specs from Go source code via static analysis with automatic framework detection.
- [go-enum](go-enum.md) — Code generation for enums from code comments.
- [go-enum-encoding](go-enum-encoding.md) — Code generation for enum encoding from code comments.
- [go-linq](go-linq.md) — .NET LINQ-like query methods for Go.
- [goderive](goderive.md) — Derives functions from input types
- [goverter](goverter.md) — Generate converters by defining an interface.
- [GoWrap](gowrap.md) — Generate decorators for Go interfaces using simple templates.
- [interfaces](interfaces.md) — Command line tool for generating interface definitions.
- [jennifer](jennifer.md) — Generate arbitrary Go code without templates.
- [oapi-codegen](oapi-codegen.md) — This package contains a set of utilities for generating Go boilerplate code for services based on OpenAPI 3.0 API definitions.
- [protoc-gen-httpgo](protoc-gen-httpgo.md) — Generate HTTP server and client from protobuf.
- [protoc-gen-mcp](protoc-gen-mcp.md) — Generate typed MCP tools, prompts, and resources from Protocol Buffers.
- [typeregistry](typeregistry.md) — A library to create type dynamically.
