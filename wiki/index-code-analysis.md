# Code Analysis

- [apicompat](apicompat.md) — Checks recent changes to a Go project for backwards incompatible changes.
- [ast-metrics](ast-metrics.md) — Static code analyzer for Go and other languages: complexity, coupling, cohesion and maintainability metrics, with HTML, JSON, Markdown and SARIF reports.
- [asty](asty.md) — Converts golang AST to JSON and JSON to AST.
- [blanket](blanket.md) — blanket is a tool that helps you catch functions which don't have direct unit tests in your Go packages.
- [ChainJacking](chainjacking.md) — Find which of your Go lang direct GitHub dependencies is susceptible to ChainJacking attack.
- [Chronos](chronos.md) — Detects race conditions statically
- [deadmono](deadmono.md) — Wrapper around deadcode for detection of dead code in Go monorepo.
- [dupl](dupl.md) — Tool for code clone detection.
- [errcheck](errcheck.md) — Errcheck is a program for checking for unchecked errors in Go programs.
- [fatcontext](fatcontext.md) — Fatcontext detects nested contexts in loops or function literals.
- [go-checkstyle](go-checkstyle.md) — checkstyle is a style check tool like java checkstyle. This tool inspired by java checkstyle, golint. The style referred to some points in Go Code Review…
- [go-cleanarch](go-cleanarch.md) — go-cleanarch was created to validate Clean Architecture rules, like a The Dependency Rule and interaction between packages in your Go projects.
- [go-critic](go-critic.md) — source code linter that brings checks that are currently not implemented in other linters.
- [go-mod-outdated](go-mod-outdated.md) — An easy way to find outdated dependencies of your Go projects.
- [goast-viewer](goast-viewer.md) — Web based Golang AST visualizer.
- [gocondense](gocondense.md) — A gofmt-compatible formatter that condenses multi-line constructs onto single lines where they fit.
- [goimports](goimports.md) — Tool to fix (add, remove) your Go imports automatically.
- [golang-ifood-sdk](golang-ifood-sdk.md) — iFood API SDK.
- [golangci-lint](golangci-lint.md) — – A fast Go linters runner. It runs linters in parallel, uses caching, supports yaml config, has integrations with all major IDE and has dozens of linters…
- [golines](golines.md) — Formatter that automatically shortens long lines in Go code.
- [gomarklint](gomarklint.md) — Markdown linter with built-in HTTP link validation, single binary, no Node.js required.
- [GoPlantUML](goplantuml.md) — Library and CLI that generates text plantump class diagram containing information about structures and interfaces with the relationship among them.
- [goreturns](goreturns.md) — Adds zero-value return statements to match the func return types.
- [gostatus](gostatus.md) — Command line tool, shows the status of repositories that contain Go packages.
- [lint](lint.md) — Run linters as part of go test.
- [php-parser](php-parser.md) — A Parser for PHP written in Go.
- [revive](revive.md) — – ~6x faster, stricter, configurable, extensible, and beautiful drop-in replacement for golint.
- [staticcheck](staticcheck.md) — staticcheck is go vet on steroids, applying a ton of static analysis checks you might be used to from tools like ReSharper for C#.
- [structalign](structalign.md) — Shows how a struct's fields could be reordered to use less memory, printing a diff instead of rewriting files.
- [stto](stto.md) — A light-weight superfast line of code counter written in pure Go.
- [testifylint](testifylint.md) — – A linter that checks usage of github.com/stretchr/testify.
- [tickgit](tickgit.md) — CLI and go package for surfacing code comment TODOs (in any language) and applying a git blameto identify the author.
- [todocheck](todocheck.md) — Static code analyser which links TODO comments in code with issues in your issue tracker.
- [unconvert](unconvert.md) — Remove unnecessary type conversions from Go source.
- [usestdlibvars](usestdlibvars.md) — A linter that detect the possibility to use variables/constants from the Go standard library.
- [vacuum](vacuum.md) — An ultra-super-fast, lightweight OpenAPI linter and quality checking tool.
- [validate](validate-3.md) — Automatically validates struct fields with tags.
- [wrapcheck](wrapcheck.md) — A linter to check that errors from external packages are wrapped.
