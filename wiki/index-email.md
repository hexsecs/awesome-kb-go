# Email

- [chasquid](chasquid.md) — SMTP server written in Go.
- [douceur](douceur.md) — CSS inliner for your HTML emails.
- [email](email.md) — A robust and flexible email library for Go.
- [email-verifier](email-verifier.md) — A Go library for email verification without sending any emails.
- [go-dkim](go-dkim.md) — DKIM library, to sign & verify email.
- [go-email-normalizer](go-email-normalizer.md) — Golang library for providing a canonical representation of email address.
- [go-imap](go-imap.md) — Batteries-included IMAP client with auto-reconnect, OAuth2, IDLE support, and built-in MIME parsing.
- [go-imap](go-imap-2.md) — IMAP library for clients and servers.
- [go-mail](go-mail.md) — A simple Go library for sending mails in Go.
- [go-message](go-message.md) — Streaming library for the Internet Message Format and mail messages.
- [go-premailer](go-premailer.md) — Inline styling for HTML mail in Go.
- [go-simple-mail](go-simple-mail.md) — Very simple package to send emails with SMTP Keep Alive and two timeouts: Connect and Send.
- [go-spamcheck](go-spamcheck.md) — Client for Postmark's SpamCheck API that scores a raw email against SpamAssassin rules.
- [Hectane](hectane.md) — Lightweight SMTP client providing an HTTP API.
- [hermes](hermes.md) — Golang package that generates clean, responsive HTML e-mails.
- [Maddy](maddy.md) — All-in-one (SMTP, IMAP, DKIM, DMARC, MTA-STS, DANE) email server
- [mailchain](mailchain.md) — Send encrypted emails to blockchain addresses written in Go.
- [mailgun-go](mailgun-go.md) — Go library for sending mail with the Mailgun API.
- [MailHog](mailhog.md) — Email and SMTP testing with web and API interface.
- [Mailpit](mailpit.md) — Email and SMTP testing tool for developers.
- [mailx](mailx.md) — Mailx is a library that makes it easier to send email via SMTP. It is an enhancement of the golang standard library net/smtp.
- [mox](mox.md) — Modern full-featured secure mail server for low-maintenance, self-hosted email.
- [SendGrid](sendgrid.md) — SendGrid's Go library for sending email.
- [smtp](smtp.md) — SMTP server protocol state machine.
- [smtpmock](smtpmock.md) — Lightweight configurable multithreaded fake SMTP server. Mimic any SMTP behaviour for your test environment.
- [tickstem/verify](tickstem-verify.md) — Validate email addresses before they hit your database: syntax, MX lookup, disposable domains, and role-based inboxes.
- [truemail-go](truemail-go.md) — Configurable Golang email validator/verifier. Verify email via Regex, DNS, SMTP and even more.
