# IoT (Internet of Things)

- [connectordb](connectordb.md) — Open-Source Platform for Quantified Self & IoT.
- [devices](devices.md) — Suite of libraries for IoT devices, experimental for x/exp/io.
- [ekuiper](ekuiper.md) — Lightweight data stream processing engine for IoT edge.
- [eywa](eywa.md) — Project Eywa is essentially a connection manager that keeps track of connected devices.
- [flogo](flogo.md) — Project Flogo is an Open Source Framework for IoT Edge Apps & Integration.
- [gatt](gatt.md) — Gatt is a Go package for building Bluetooth Low Energy peripherals.
- [gobot](gobot.md) — Gobot is a framework for robotics, physical computing, and the Internet of Things.
- [huego](huego.md) — An extensive Philips Hue client library for Go.
- [iot](iot.md) — IoT is a simple framework for implementing a Google IoT Core device.
- [periph](periph.md) — Peripherals I/O to interface with low-level board facilities.
- [rulego](rulego.md) — RuleGo is a lightweight, high-performance, embedded, orchestrable component-based rule engine for IoT edge.
- [sensorbee](sensorbee.md) — Lightweight stream processing engine for IoT.
- [shifu](shifu.md) — Kubernetes native IoT development framework.
- [smart-home](smart-home.md) — Software package for IoT automation.
