# Reflection

- [copy](copy-2.md) — Package for fast copying structs of different types.
- [Deepcopier](deepcopier.md) — Simple struct copying for Go.
- [go-deepcopy](go-deepcopy.md) — Fast deep copy library.
- [goenum](goenum.md) — A common enumeration struct based on generics and reflection that allows you to quickly define enumerations and use a set of useful default methods.
- [gotype](gotype.md) — Golang source code parsing, usage like reflect package.
- [gpath](gpath.md) — Library to simplify access struct fields with Go's expression in reflection.
- [objwalker](objwalker.md) — Walk by go objects with reflection.
- [reflectpro](reflectpro.md) — Callers, copiers, getters and setters for go.
- [reflectutils](reflectutils.md) — Helpers for working with reflection: struct tag parsing; recursive walking; fill value from string.
