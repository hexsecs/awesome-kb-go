# Geographic

- [borders](borders.md) — Detects image borders and converts to GeoJSON for GIS operations.
- [geo-engine-go](geo-engine-go.md) — Official Go SDK for GeoEngine, offering high-performance geospatial data ingestion with single-digit millisecond latency.
- [geoos](geoos.md) — A library provides spatial data and geometric algorithms.
- [geoserver](geoserver.md) — geoserver Is a Go Package For Manipulating a GeoServer Instance via the GeoServer REST API.
- [gismanager](gismanager.md) — Publish Your GIS Data(Vector Data) to PostGIS and Geoserver.
- [godal](godal.md) — Go wrapper for GDAL.
- [H3](h3.md) — Go bindings for H3, a hierarchical hexagonal geospatial indexing system.
- [H3 GeoJSON](h3-geojson.md) — Conversion utilities between H3 indexes and GeoJSON.
- [H3GeoDist](h3geodist.md) — Distribution of Uber H3geo cells by virtual nodes.
- [mbtileserver](mbtileserver.md) — A simple Go-based server for map tiles stored in mbtiles format.
- [osm](osm.md) — Library for reading, writing and working with OpenStreetMap data and APIs.
- [pbf](pbf.md) — OpenStreetMap PBF golang encoder/decoder.
- [S2 geojson](s2-geojson.md) — Convert geojson to s2 cells & demonstrating some S2 geometry features on map.
- [S2 geometry](s2-geometry.md) — S2 geometry library in Go.
- [simplefeatures](simplefeatures.md) — simplesfeatures is a 2D geometry library that provides Go types that model geometries, as well as algorithms that operate on them.
- [Tile38](tile38.md) — Geolocation DB with spatial index and realtime geofencing.
- [Web-Mercator-Projection](web-mercator-projection.md) — A project to easily use and convert LonLat, Point and Tile to display info, markers, etc, in a map using the Web Mercator Projection.
- [WGS84](wgs84.md) — Library for Coordinate Conversion and Transformation (ETRS89, OSGB36, NAD83, RGF93, Web Mercator, UTM).
