# Web Frameworks / Middlewares / Libraries for creating HTTP middlewares

- [alice](alice-2.md) — Painless middleware chaining for Go.
- [catena](catena.md) — http.Handler wrapper catenation (same API as "chain").
- [chain](chain.md) — Handler wrapper chaining with scoped data (net/context-based "middleware").
- [gores](gores.md) — Go package that handles HTML, JSON, XML and etc. responses. Useful for RESTful APIs.
- [interpose](interpose.md) — Minimalist net/http middleware for golang.
- [mediary](mediary.md) — add interceptors to http.Client to allow dumping/shaping/tracing/... of requests/responses.
- [muxchain](muxchain.md) — Lightweight middleware for net/http.
- [negroni](negroni.md) — Idiomatic HTTP middleware for Golang.
- [render](render.md) — Go package for easily rendering JSON, XML, and HTML template responses.
- [renderer](renderer.md) — Simple, lightweight and faster response (JSON, JSONP, XML, YAML, HTML, File) rendering package for Go.
- [stats](stats-3.md) — Go middleware that stores various information about your web application.
