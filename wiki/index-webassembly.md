# WebAssembly

- [dom](dom.md) — DOM library.
- [Extism Go SDK](extism-go-sdk.md) — Universal, cross-language WebAssembly framework for building plug-in systems and polyglot apps.
- [go-canvas](go-canvas.md) — Library to use HTML5 Canvas, with all drawing within go code.
- [tinygo](tinygo.md) — Go compiler for small places. Microcontrollers, WebAssembly, and command-line tools. Based on LLVM.
- [vert](vert.md) — Interop between Go and JS values.
- [wasmbrowsertest](wasmbrowsertest.md) — Run Go WASM tests in your browser.
- [wasmtime-go](wasmtime-go.md) — Go bindings for the Wasmtime WebAssembly runtime (WASI support, JIT/AOT, secure and fast embedding).
- [webapi](webapi.md) — Bindings for DOM and HTML generated from WebIDL.
