# Natural Language Processing / Language Detection

- [detectlanguage](detectlanguage.md) — Language Detection API Go Client. Supports batch requests, short phrase or single word language detection.
- [getlang](getlang.md) — Fast natural language detection package.
- [guesslanguage](guesslanguage.md) — Functions to determine the natural language of a unicode text.
- [lingua-go](lingua-go.md) — An accurate natural language detection library, suitable for long and short text alike. Supports detecting multiple languages in mixed-language text.
- [whatlanggo](whatlanggo.md) — Natural language detection package for Go. Supports 84 languages and 24 scripts (writing systems e.g. Latin, Cyrillic, etc).
