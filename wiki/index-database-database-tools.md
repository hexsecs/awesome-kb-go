# Database / Database Tools

- [chproxy](chproxy.md) — HTTP proxy for ClickHouse database.
- [clickhouse-bulk](clickhouse-bulk.md) — Collects small inserts and sends big requests to ClickHouse servers.
- [clickhouse-sql-parser](clickhouse-sql-parser.md) — Parser for ClickHouse-dialect SQL that produces a typed AST, with traversal helpers, round-trip formatting, and a CLI.
- [database-gateway](database-gateway.md) — Running SQL in production with ACLs, logs, and shared links.
- [dbbench](dbbench.md) — Database benchmarking tool with support for several databases and scripts.
- [dg](dg.md) — A fast data generator that produces CSV files from generated relational data.
- [filesql](filesql.md) — Query CSV, TSV, LTSV, JSON, JSONL, Parquet, Excel, ACH, and Fedwire files with SQL through the database/sql API, backed by in-memory SQLite.
- [gatewayd](gatewayd.md) — Cloud-native database gateway and framework for building data-driven applications. Like API gateways, for databases.
- [go-mysql](go-mysql.md) — Go toolset to handle MySQL protocol and replication.
- [go-postgres-s3-backup](go-postgres-s3-backup.md) — Serverless PostgreSQL backups to S3 using AWS Lambda, with daily, monthly, and yearly rotation.
- [gorm-multitenancy](gorm-multitenancy.md) — Multi-tenancy support for GORM managed databases.
- [GoSQLX](gosqlx.md) — High-performance SQL parser, formatter, linter, and security scanner with multi-dialect support and WASM playground.
- [hasql](hasql.md) — Library for accessing multi-host SQL database installations.
- [octillery](octillery.md) — Go package for sharding databases ( Supports every ORM or raw SQL ).
- [onedump](onedump.md) — Database backup from different drivers to different destinations with one command and configuration.
- [pg_timetable](pg-timetable.md) — Advanced scheduling for PostgreSQL.
- [pgrwl](pgrwl.md) — Cloud-native continuous backup for PostgreSQL.
- [pgwd](pgwd.md) — CLI that monitors PostgreSQL connection counts (total, active, idle, stale) and notifies via Slack and/or Loki when thresholds are exceeded. Supports…
- [pgweb](pgweb.md) — Web-based PostgreSQL database browser.
- [pgxcli](pgxcli.md) — PostgreSQL CLI client written in Go, inspired by pgcli.
- [prep](prep.md) — Use prepared SQL statements without changing your code.
- [pREST](prest.md) — Simplify and accelerate development, ⚡ instant, realtime, high-performance on any Postgres application, existing or new.
- [rdb](rdb.md) — Redis RDB file parser for secondary development and memory analysis.
- [rwdb](rwdb.md) — rwdb provides read replica capability for multiple database servers setup.
- [sqly](sqly.md) — Execute SQL against CSV, TSV, LTSV, JSON, Parquet, and Excel files in an interactive shell, backed by in-memory SQLite.
- [vitess](vitess.md) — vitess provides servers and tools which facilitate scaling of MySQL databases for large scale web services.
- [wescale](wescale.md) — WeScale is a database proxy designed to enhance the scalability, performance, security, and resilience of your applications.
- [xsql](xsql.md) — AI-first cross-database CLI tool with read-only protection and structured JSON output.
