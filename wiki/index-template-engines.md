# Template Engines

- [bagme](bagme.md) — HTML/CSS to PDF rendering with TeX-quality typesetting in pure Go.
- [ego](ego.md) — Lightweight templating language that lets you write templates in Go. Templates are translated into Go and compiled.
- [fasttemplate](fasttemplate.md) — Simple and fast template engine. Substitutes template placeholders up to 10x faster than text/template.
- [gomponents](gomponents.md) — HTML 5 components in pure Go, that look something like this: func(name string) g.Node { return Div(Class("headline"), g.Textf("Hi %v!", name)) }.
- [got](got.md) — A Go code generator inspired by Hero and Fasttemplate. Has include files, custom tag definitions, injected Go code, language translation, and more.
- [goview](goview.md) — Goview is a lightweight, minimalist and idiomatic template library based on golang html/template for building Go web application.
- [gox](gox.md) — HTML templates as first-class Go expressions, with seamless editor support.
- [htmgo](htmgo.md) — build simple and scalable systems with go + htmx
- [jet](jet-2.md) — Jet template engine.
- [liquid](liquid.md) — Go implementation of Shopify Liquid templates.
- [liquidgo](liquidgo.md) — Full Go implementation of Shopify's Liquid template engine.
- [maroto](maroto.md) — A maroto way to create PDFs. Maroto is inspired in Bootstrap and uses gofpdf. Fast and simple.
- [pongo2](pongo2.md) — Django-like template-engine for Go.
- [quicktemplate](quicktemplate.md) — Fast, powerful, yet easy to use template engine. Converts templates into Go code and then compiles it.
- [Razor](razor.md) — Razor view engine for Golang.
- [Soy](soy.md) — Closure templates (aka Soy templates) for Go, following the official spec.
- [sprout](sprout.md) — Useful template functions for Go templates.
- [tbd](tbd.md) — A really simple way to create text templates with placeholders - exposes extra builtin Git repo metadata.
- [templ](templ.md) — A HTML templating language that has great developer tooling.
- [templator](templator.md) — A type-safe HTML template rendering engine for Go.
