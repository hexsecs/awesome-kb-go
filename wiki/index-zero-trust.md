# Zero Trust

- [Cosign](cosign.md) — Container Signing, Verification and Storage in an OCI registry.
- [in-toto](in-toto.md) — Go implementation of the in-toto (provides a framework to protect the integrity of the software supply chain) python reference implementation.
- [OpenZiti](openziti.md) — A full, open source zero trust overlay network. Including numerous SDKs for numerous languages such as golang allowing you to embed zero trust principles…
- [Spiffe-Vault](spiffe-vault.md) — Utilizes Spiffe JWT authentication with Hashicorp Vault for secretless authentication.
- [Spire](spire.md) — SPIRE (the SPIFFE Runtime Environment) is a toolchain of APIs for establishing trust between software systems across a wide variety of hosting platforms.
