# Serialization

- [bambam](bambam.md) — generator for Cap'n Proto schemas from go.
- [bel](bel.md) — Generate TypeScript interfaces from Go structs/interfaces. Useful for JSON RPC.
- [binstruct](binstruct.md) — Golang binary decoder for mapping data into the structure.
- [cbor](cbor.md) — Small, safe, and easy CBOR encoding and decoding library.
- [colfer](colfer.md) — Code generation for the Colfer binary format.
- [csvutil](csvutil.md) — High Performance, idiomatic CSV record encoding and decoding to native Go structures.
- [elastic](elastic-2.md) — Convert slices, maps or any other unknown value across different types at run-time, no matter what.
- [fixedwidth](fixedwidth.md) — Fixed-width text formatting (UTF-8 supported).
- [fwencoder](fwencoder.md) — Fixed width file parser (encoding and decoding library) for Go.
- [go-capnproto](go-capnproto.md) — Cap'n Proto library and parser for go.
- [go-codec](go-codec.md) — High Performance, feature-Rich, idiomatic encode, decode and rpc library for msgpack, cbor and json, with runtime-based OR code-generation support.
- [go-csvlib](go-csvlib.md) — High level and rich functionalities CSV serialization/deserialization library.
- [goprotobuf](goprotobuf.md) — Go support, in the form of a library and protocol compiler plugin, for Google's protocol buffers.
- [gotiny](gotiny.md) — Efficient Go serialization library, gotiny is almost as fast as serialization libraries that generate code.
- [jsoniter](jsoniter.md) — High-performance 100% compatible drop-in replacement of "encoding/json".
- [mus-go](mus-go.md) — MUS format serializer for Go.
- [php_session_decoder](php-session-decoder.md) — GoLang library for working with PHP session format and PHP Serialize/Unserialize functions.
- [pletter](pletter.md) — A standard way to wrap a proto message for message brokers.
- [proto](proto.md) — Parser and writer for Google ProtocolBuffers .proto files.
- [structomap](structomap.md) — Library to easily and dynamically generate maps from static structures.
- [unitpacking](unitpacking.md) — Library to pack unit vectors into as fewest bytes as possible.
