# Text Processing / Markup Languages

- [bafi](bafi.md) — Universal JSON, BSON, YAML, XML translator to ANY format using templates.
- [bbConvert](bbconvert.md) — Converts bbCode to HTML that allows you to add support for custom bbCode tags.
- [blackfriday](blackfriday.md) — Markdown processor in Go.
- [go-output-format](go-output-format.md) — Output go structures into multiple formats (YAML/JSON/etc) in your command line app.
- [go-toml](go-toml.md) — Go library for the TOML format with query support and handy cli tools.
- [goldmark](goldmark.md) — A Markdown parser written in Go. Easy to extend, standard (CommonMark) compliant, well structured.
- [goq](goq.md) — Declarative unmarshalling of HTML using struct tags with jQuery syntax (uses GoQuery).
- [html-to-markdown](html-to-markdown.md) — Convert HTML to Markdown. Even works with entire websites and can be extended through rules.
- [htmlquery](htmlquery.md) — An XPath query package for HTML, lets you extract data or evaluate from HTML documents by an XPath expression.
- [htmlyaml](htmlyaml.md) — Rich rendering of YAML as HTML in Go.
- [htree](htree.md) — Traverse, navigate, filter, and otherwise process trees of html.Node objects.
- [markdown](markdown.md) — Markdown builder that generates GitHub Flavored Markdown and mermaid diagrams through method chaining.
- [mdsmith](mdsmith.md) — fast, auto-fixing Markdown linter and formatter. Checks style, readability, structure, and cross-file integrity.
- [mxj](mxj.md) — Encode / decode XML as JSON or map[string]interface{}; extract values with dot-notation paths and wildcards. Replaces x2j and j2x packages.
- [picoloom](picoloom.md) — Markdown-to-PDF converter with CLI and Go library APIs.
- [toml](toml.md) — TOML configuration format (encoder/decoder with reflection).
