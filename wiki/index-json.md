# JSON

- [ajson](ajson.md) — Abstract JSON for golang with JSONPath support.
- [ask](ask.md) — Easy access to nested values in maps and slices. Works in combination with encoding/json and other packages that "Unmarshal" arbitrary data into Go data-types.
- [dynjson](dynjson.md) — Client-customizable JSON formats for dynamic APIs.
- [ej](ej.md) — Write and read JSON from different sources succinctly.
- [epoch](epoch.md) — Contains primitives for marshaling/unmarshalling Unix timestamp/epoch to/from build-in time.Time type in JSON.
- [fastjson](fastjson.md) — Fast JSON parser and validator for Go. No custom structs, no code generation, no reflection.
- [gabs](gabs.md) — For parsing, creating and editing unknown or dynamic JSON in Go.
- [gjo](gjo.md) — Small utility to create JSON objects.
- [GJSON](gjson.md) — Get a JSON value with one line of code.
- [go-jsonerror](go-jsonerror.md) — Go-JsonError is meant to allow us to easily create json response errors that follow the JsonApi spec.
- [go-respond](go-respond.md) — Go package for handling common HTTP JSON responses.
- [gojmapr](gojmapr.md) — Get simple struct from complex json by json path.
- [gojq](gojq.md) — JSON query in Golang.
- [gojson](gojson.md) — Automatically generate Go (golang) struct definitions from example JSON.
- [htmljson](htmljson.md) — Rich rendering of JSON as HTML in Go.
- [JayDiff](jaydiff.md) — JSON diff utility written in Go.
- [jettison](jettison.md) — Fast and flexible JSON encoder for Go.
- [jscan](jscan.md) — High performance zero-allocation JSON iterator.
- [jseq](jseq.md) — Streaming JSON parser.
- [json2go](json2go.md) — Advanced JSON to Go struct conversion. Provides package that can parse multiple JSON documents and create struct to fit them all.
- [jsonapi-errors](jsonapi-errors.md) — Go bindings based on the JSON API errors reference.
- [jsoncolor](jsoncolor.md) — Drop-in replacement for encoding/json that outputs colorized JSON.
- [jsondiff](jsondiff.md) — JSON diff library for Go based on RFC6902 (JSON Patch).
- [jsonf](jsonf.md) — Console tool for highlighted formatting and struct query fetching JSON.
- [jsongo](jsongo.md) — Fluent API to make it easier to create Json objects.
- [jsonhal](jsonhal.md) — Simple Go package to make custom structs marshal into HAL compatible JSON responses.
- [jsonhandlers](jsonhandlers.md) — JSON library to expose simple handlers that lets you easily read and write json from various sources.
- [jsonic](jsonic.md) — Utilities to handle and query JSON without defining structs in a type safe manner.
- [jsonvalue](jsonvalue.md) — A fast and convenient library for unstructured JSON data, replacing encoding/json.
- [jzon](jzon.md) — JSON library with standard compatible API/behavior.
- [kazaam](kazaam.md) — API for arbitrary transformation of JSON documents.
- [mapslice-json](mapslice-json.md) — Go MapSlice for ordered marshal/ unmarshal of maps in JSON.
- [marshmallow](marshmallow.md) — Performant JSON unmarshalling for flexible use cases.
- [mp](mp.md) — Simple cli email parser. It currently takes stdin and outputs JSON.
- [OjG](ojg.md) — Optimized JSON for Go is a high performance parser with a variety of additional JSON tools including JSONPath.
- [omg.jsonparser](omg-jsonparser.md) — Simple JSON parser with validation by condition via golang struct fields tags.
- [silentjson](silentjson.md) — Zero-allocation JSON boundary scanner and splitter utilizing AVX2 SIMD instructions.
- [SJSON](sjson.md) — Set a JSON value with one line of code.
- [ujson](ujson.md) — Fast and minimal JSON parser and transformer that works on unstructured JSON.
- [vjson](vjson.md) — Go package for validating JSON objects with declaring a JSON schema with fluent API.
