# Server Applications

- [algernon](algernon.md) — HTTP/2 web server with built-in support for Lua, Markdown, GCSS and Amber.
- [Caddy](caddy.md) — Caddy is an alternative, HTTP/2 web server that's easy to configure and use.
- [Casdoor](casdoor.md) — Identity and access management (IAM) and single sign-on (SSO) server with a web UI, supporting OAuth 2.0, OIDC, SAML, CAS and LDAP.
- [consul](consul.md) — Consul is a tool for service discovery, monitoring and configuration.
- [cortex-tenant](cortex-tenant.md) — Prometheus remote write proxy that adds add Cortex tenant ID header based on metric labels.
- [devd](devd.md) — Local webserver for developers.
- [discovery](discovery.md) — A registry for resilient mid-tier load balancing and failover.
- [dudeldu](dudeldu.md) — A simple SHOUTcast server.
- [Easegress](easegress.md) — A cloud native high availability/performance traffic orchestration system with observability and extensibility.
- [Engity's Bifröst](engity-s-bifr-st.md) — Highly customizable SSH server with several ways to authorize a user how to execute its session (local or in containers).
- [etcd](etcd.md) — Highly-available key value store for shared configuration and service discovery.
- [Euterpe](euterpe.md) — Self-hosted music streaming server with built-in web UI and REST API.
- [Fider](fider.md) — Fider is an open platform to collect and organize customer feedback.
- [Flagr](flagr.md) — Flagr is an open-source feature flagging and A/B testing service.
- [flipt](flipt.md) — A self contained feature flag solution written in Go and Vue.js
- [flue](flue.md) — Self-hosted daemon that serves terminal sessions to a browser tab. Sessions keep running after the tab is closed.
- [go-feature-flag](go-feature-flag.md) — A simple, complete and lightweight self-hosted feature flag solution 100% Open Source.
- [go-proxy-cache](go-proxy-cache.md) — Simple Reverse Proxy with Caching, written in Go, using Redis.
- [gondola](gondola.md) — A YAML based golang reverse proxy.
- [goshs](goshs.md) — SimpleHTTPServer replacement with file upload/download, WebDAV, SFTP, SMB, TLS, authentication, and share links.
- [Kono](kono.md) — lightweight extendable API Gateway in Go - parallel fan-out, flexible aggregation, and zero configuration magic.
- [lets-proxy2](lets-proxy2.md) — Reverse proxy for handle https with issue certificates in fly from lets-encrypt.
- [minio](minio.md) — Community Maintained Fork of minio (Object Storage Service).
- [Moxy](moxy.md) — Moxy is a simple mocker and proxy application server, you can create mock endpoints as well as proxy requests in case no mock exists for the endpoint.
- [nginx-prometheus](nginx-prometheus.md) — Nginx log parser and exporter to Prometheus.
- [nsq](nsq.md) — A realtime distributed messaging platform.
- [OpenRun](openrun.md) — Open-source alternative to Google Cloud Run and AWS App Runner. Easily deploy internal tools across a team.
- [pocketbase](pocketbase.md) — PocketBase is a realtime backend in 1 file consisting of embedded database (SQLite) with realtime subscriptions, built-in auth management and much more.
- [protoxy](protoxy.md) — A proxy server that converts JSON request bodies to Protocol Buffers.
- [psql-streamer](psql-streamer.md) — Stream database events from PostgreSQL to Kafka.
- [relay](relay.md) — MCP server with 40+ tools for AI agents. File operations, web search, screenshots, multi-agent coordination. Single Go binary.
- [riemann-relay](riemann-relay.md) — Relay to load-balance Riemann events and/or convert them to Carbon.
- [RoadRunner](roadrunner.md) — High-performance PHP application server, load-balancer and process manager.
- [SFTPGo](sftpgo.md) — Fully featured and highly configurable SFTP server with optional FTP/S and WebDAV support. It can serve local filesystem and Cloud Storage backends such as…
- [simpleconf](simpleconf.md) — Configuration server holding one JSON document, read and written by key path over HTTP and TCP, with optional Raft clustering.
- [Trickster](trickster.md) — HTTP reverse proxy cache and time series accelerator.
- [wd-41](wd-41.md) — A (w)eb (d)evelopment server with automatic live-reload on file changes.
- [whois](whois.md) — Self-hosted WHOIS/RDAP query service and MCP server for domains, IPv4/IPv6 addresses, CIDRs and ASNs.
- [Wish](wish.md) — Make SSH apps, just like that!
