# GUI

- [app](app.md) — Package to create apps with GO, HTML and CSS. Supports: MacOS, Windows in progress.
- [cimgui-go](cimgui-go.md) — Auto generated Go wrapper for Dear ImGui via cimgui.
- [Cogent Core](cogent-core.md) — A framework for building 2D and 3D apps that run on macOS, Windows, Linux, iOS, Android, and the web.
- [DarwinKit](darwinkit.md) — Build native macOS applications using Go.
- [energy](energy.md) — Cross-platform based on LCL(Native System UI Control Library) and CEF(Chromium Embedded Framework) (Windows/ macOS / Linux)
- [fyne](fyne.md) — Cross platform native GUIs designed for Go based on Material Design. Supports: Linux, macOS, Windows, BSD, iOS and Android.
- [gio](gio.md) — Gio is a library for writing cross-platform immediate mode GUI-s in Go. Gio supports all the major platforms: Linux, macOS, Windows, Android, iOS, FreeBSD…
- [go-gtk](go-gtk.md) — Go bindings for GTK.
- [go-sciter](go-sciter.md) — Go bindings for Sciter: the Embeddable HTML/CSS/script engine for modern desktop UI development. Cross platform.
- [Goey](goey.md) — Cross platform UI toolkit aggregator for Windows / Linux / Mac. GTK, Cocoa, Windows API
- [gogpu/ui](gogpu-ui.md) — GPU-accelerated GUI toolkit with 22 widgets, 3 design systems (Material, Fluent, Cupertino), reactive signals, and zero CGO (part of GoGPU ecosystem).
- [goradd/html5tag](goradd-html5tag.md) — Library for outputting HTML5 tags.
- [gotk3](gotk3.md) — Go bindings for GTK3.
- [gowd](gowd.md) — Rapid and simple desktop UI development with GO, HTML, CSS and NW.js. Cross platform.
- [proton](proton.md) — Pure Go immediate-mode GUI framework built on Gio with zero Cgo dependencies.
- [qt](qt.md) — Qt binding for Go (support for Windows / macOS / Linux / Android / iOS / Sailfish OS / Raspberry Pi).
- [Spot](spot.md) — Reactive, cross-platform desktop GUI toolkit.
- [ui](ui.md) — Platform-native GUI library for Go. Cross platform.
- [unison](unison.md) — A unified graphical user experience toolkit for Go desktop applications. macOS, Windows, and Linux are supported.
- [Wails](wails.md) — Mac, Windows, Linux desktop apps with HTML UI using built-in OS HTML renderer.
- [walk](walk.md) — Windows application library kit for Go.
- [webview](webview.md) — Cross-platform webview window with simple two-way JavaScript bindings (Windows / macOS / Linux).
- [AppIndicator Go](appindicator-go.md) — Go bindings for libappindicator3 C library.
- [gogpu/systray](gogpu-systray.md) — Pure Go system tray library for Windows, macOS, and Linux with zero CGO (part of GoGPU ecosystem).
- [gosx-notifier](gosx-notifier.md) — OSX Desktop Notifications library for Go.
- [mac-activity-tracker](mac-activity-tracker.md) — OSX library to notify about any (pluggable) activity on your machine.
- [mac-sleep-notifier](mac-sleep-notifier.md) — OSX Sleep/Wake notifications in golang.
- [robotgo](robotgo.md) — Go Native cross-platform GUI system automation. Control the mouse, keyboard and other.
- [systray](systray.md) — Cross platform Go library to place an icon and menu in the notification area.
- [trayhost](trayhost.md) — Cross-platform Go library to place an icon in the host operating system's taskbar.
- [zenity](zenity.md) — Cross-platform Go library and CLI to create simple dialogs that interact graphically with the user.
