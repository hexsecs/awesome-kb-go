# Continuous Integration

- [abstruse](abstruse.md) — Abstruse is a distributed CI platform.
- [Bencher](bencher.md) — A suite of continuous benchmarking tools designed to catch performance regressions in CI.
- [CDS](cds.md) — Enterprise-Grade CI/CD and DevOps Automation Open Source Platform.
- [dot](dot.md) — A minimal, local first continuous integration system that uses Docker to run jobs concurrently in stages.
- [drone](drone.md) — Drone is a Continuous Integration platform built on Docker, written in Go.
- [go-beautiful-html-coverage](go-beautiful-html-coverage.md) — A GitHub Action to track code coverage in your pull requests, with a beautiful HTML preview, for free.
- [go-fuzz-action](go-fuzz-action.md) — Use Go 1.18's built-in fuzz testing in GitHub Actions.
- [go-semver-release](go-semver-release.md) — Automate the semantic versioning of Git repositories.
- [go-test-coverage](go-test-coverage.md) — A GitHub Action which reports issues when test coverage is below set threshold.
- [gomason](gomason.md) — Test, Build, Sign, and Publish your go binaries from a clean workspace.
- [gotestfmt](gotestfmt.md) — go test output for humans.
- [goveralls](goveralls.md) — Go integration for Coveralls.io continuous code coverage tracking system.
- [muffet](muffet.md) — Fast website link checker in Go, see alternatives.
- [overalls](overalls.md) — Multi-Package go project coverprofile for tools like goveralls.
- [PikoCI](pikoci.md) — Self-hosted CI/CD inspired by Concourse. Single binary, any database, any queue. HCL pipelines, pluggable resource types and runners.
- [roveralls](roveralls.md) — Recursive coverage testing tool.
- [woodpecker](woodpecker.md) — Woodpecker is a community fork of the Drone CI system.
