# Networking / HTTP Clients

- [axios4go](axios4go.md) — A Go HTTP client library inspired by Axios, providing a simple and intuitive API for making HTTP requests.
- [azuretls-client](azuretls-client.md) — An easy-to-use HTTP client 100% in Go to spoof TLS/JA3 and HTTP2 fingerprint.
- [fast-shot](fast-shot.md) — Hit your API targets with rapid-fire precision using Go's fastest and simple HTTP Client.
- [gentleman](gentleman.md) — Full-featured plugin-driven HTTP client library.
- [go-cleanhttp](go-cleanhttp.md) — Get easily stdlib HTTP client, which does not share any state with other clients.
- [go-http-client](go-http-client.md) — Make http calls simply and easily.
- [go-ipmux](go-ipmux.md) — A library for Multiplexing HTTP requests based on multiple Source IPs.
- [go-otelroundtripper](go-otelroundtripper.md) — Go http.RoundTripper that emits open telemetry metrics for HTTP requests.
- [go-req](go-req.md) — Declarative golang HTTP client.
- [go-retryablehttp](go-retryablehttp.md) — Retryable HTTP client in Go.
- [go-zoox/fetch](go-zoox-fetch.md) — A Powerful, Lightweight, Easy Http Client, inspired by Web Fetch API.
- [Grequest](grequest.md) — Simple and lightweight golang package for http requests. based on powerful net/http
- [grequests](grequests.md) — A Go "clone" of the great and famous Requests library.
- [hedge](hedge.md) — Adaptive hedged requests for Go. Cuts p99 latency with zero configuration, based on Google's "The Tail at Scale" paper.
- [heimdall](heimdall.md) — An enhanced http client with retry and hystrix capabilities.
- [httpretry](httpretry.md) — Enriches the default go HTTP client with retry functionality.
- [impersonate-http](impersonate-http.md) — Drop-in net/http.Client with a byte-exact browser TLS (JA3/JA4) and HTTP/2 (Akamai) fingerprint.
- [pester](pester.md) — Go HTTP client calls with retries, backoff, and concurrency.
- [req](req.md) — Simple Go HTTP client with Black Magic (Less code and More efficiency).
- [request](request.md) — HTTP client for golang. If you have experience about axios or requests, you will love it. No 3rd dependency.
- [requests](requests.md) — HTTP requests for Gophers. Uses context.Context and doesn't hide the underlying net/http.Client, making it compatible with standard Go APIs. Also includes…
- [resty](resty.md) — Simple HTTP and REST client for Go inspired by Ruby rest-client.
- [rq](rq.md) — A nicer interface for golang stdlib HTTP client.
- [sling](sling.md) — Sling is a Go HTTP client library for creating and sending API requests.
- [surf](surf.md) — Advanced HTTP client with HTTP/1.1, HTTP/2, HTTP/3 (QUIC), SOCKS5 proxy support and browser-grade TLS fingerprinting.
- [tls-client](tls-client.md) — net/http.Client like HTTP Client with options to select specific client TLS Fingerprints to use for requests.
