# Version Control

- [cli](cli.md) — An open-source GitLab command line tool bringing GitLab's cool features to your command line.
- [froggit-go](froggit-go.md) — Froggit-Go is a Go library, allowing to perform actions on VCS providers.
- [ggc](ggc.md) — A Git CLI tool with both traditional command-line and interactive incremental-search UI, workflow support, and configurable keybindings.
- [git-courer](git-courer.md) — Local MCP server for Git operations using Ollama to save tokens and prevent secret leakage.
- [git2go](git2go.md) — Go bindings for libgit2.
- [githooks](githooks.md) — Per-repo and shared Git hooks with version control and auto update.
- [gitty](gitty.md) — Single-binary Git/GitHub CLI that replaces add→commit→push with one command; human-readable syntax, no external dependencies.
- [go-git](go-git.md) — highly extensible Git implementation in pure Go.
- [go-vcs](go-vcs.md) — manipulate and inspect VCS repositories in Go.
- [hercules](hercules.md) — gaining advanced insights from Git repository history.
- [hgo](hgo.md) — Hgo is a collection of Go packages providing read-access to local Mercurial repositories.
