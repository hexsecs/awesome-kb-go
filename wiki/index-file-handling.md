# File Handling

- [afero](afero.md) — FileSystem Abstraction System for Go.
- [afs](afs.md) — Abstract File Storage (mem, scp, zip, tar, cloud: s3, gs) for Go.
- [baraka](baraka.md) — A library to process http file uploads easily.
- [checksum](checksum.md) — Compute message digest, like MD5, SHA256, SHA1, CRC or BLAKE2s, for large files.
- [copy](copy.md) — Copy directory recursively.
- [fastwalk](fastwalk.md) — Fast parallel directory traversal library (used by fzf).
- [flop](flop.md) — File operations library which aims to mirror feature parity with GNU cp.
- [gdu](gdu.md) — Disk usage analyzer with console interface.
- [go-csv-tag](go-csv-tag.md) — Load csv file using tag.
- [go-decent-copy](go-decent-copy.md) — Copy files for humans.
- [go-exiftool](go-exiftool.md) — Go bindings for ExifTool, the well-known library used to extract as much metadata as possible (EXIF, IPTC, ...) from files (pictures, PDF, office, ...).
- [go-gtfs](go-gtfs.md) — Load gtfs files in go.
- [go-wkhtmltopdf](go-wkhtmltopdf.md) — A package to convert an HTML template to a PDF file.
- [goflat](goflat.md) — Context-aware generic flat file marshaler/unmarshaler.
- [gofs](gofs.md) — A cross-platform real-time file synchronization tool out of the box.
- [gopdfrab](gopdfrab.md) — PDF/A processing for Go.
- [gulter](gulter.md) — A simple HTTP middleware to automatically handle all your file upload needs
- [gut/yos](gut-yos.md) — Simple and reliable package for file operations like copy/move/diff/list on files, directories and symbolic links.
- [gxpdf](gxpdf.md) — Modern full-lifecycle PDF library for Go — parse, extract tables, generate, and sign documents with zero CGO dependencies.
- [higgs](higgs.md) — A tiny cross-platform Go library to hide/unhide files and directories.
- [iso9660](iso9660.md) — A package for reading and creating ISO9660 disk images
- [notify](notify.md) — File system event notification library with simple API, similar to os/signal.
- [opc](opc.md) — Load Open Packaging Conventions (OPC) files for Go.
- [parquet](parquet.md) — Read and write parquet files.
- [pathtype](pathtype.md) — Treat paths as their own type instead of using strings.
- [pdfcpu](pdfcpu.md) — PDF processor.
- [skywalker](skywalker.md) — Package to allow one to concurrently go through a filesystem with ease.
- [todotxt](todotxt.md) — Go library for Gina Trapani's todo.txt files, supports parsing and manipulating of task lists in the todo.txt format.
- [vfs](vfs.md) — A pluggable, extensible, and opinionated set of filesystem functionality for Go across a number of filesystem types such as os, S3, and GCS.
