# Embeddable Scripting Languages

- [anko](anko-2.md) — Scriptable interpreter written in Go.
- [binder](binder.md) — Go to Lua binding library, based on gopher-lua.
- [cel-go](cel-go.md) — Fast, portable, non-Turing complete expression evaluation with gradual typing.
- [ecal](ecal.md) — A simple embeddable scripting language which supports concurrent event processing.
- [expr](expr.md) — Expression evaluation engine for Go: fast, non-Turing complete, dynamic typing, static typing.
- [FrankenPHP](frankenphp.md) — PHP embedded in Go, with a net/http handler.
- [gentee](gentee.md) — Embeddable scripting programming language.
- [gisp](gisp.md) — Simple LISP in Go.
- [go-lua](go-lua.md) — Port of the Lua 5.2 VM to pure Go.
- [go-lua](go-lua-2.md) — Lua 5.4 VM implemented in pure Go.
- [go-php](go-php.md) — PHP bindings for Go.
- [goal](goal.md) — An embeddable scripting array language.
- [goja](goja.md) — ECMAScript 5.1(+) implementation in Go.
- [golua](golua.md) — Go bindings for Lua C API.
- [gopher-lua](gopher-lua.md) — Lua 5.1 VM and compiler written in Go.
- [gval](gval.md) — A highly customizable expression language written in Go.
- [metacall](metacall.md) — Cross-platform Polyglot Runtime which supports NodeJS, JavaScript, TypeScript, Python, Ruby, C#, WebAssembly, Java, Cobol and more.
- [ngaro](ngaro.md) — Embeddable Ngaro VM implementation enabling scripting in Retro.
- [prolog](prolog.md) — Embeddable Prolog.
- [purl](purl.md) — Perl 5.18.2 embedded in Go.
- [starlark-go](starlark-go.md) — Go implementation of Starlark: Python-like language with deterministic evaluation and hermetic execution.
- [starlet](starlet.md) — Go wrapper for starlark-go that simplifies script execution, offers data conversion, and useful Starlark libraries and extensions.
- [tengo](tengo.md) — Bytecode compiled script language for Go.
- [Wa/凹语言](wa.md) — The Wa Programming Language embedded in Go.
