# Video

- [gmf](gmf.md) — Go bindings for FFmpeg av\ libraries.
- [go-astiav](go-astiav.md) — Better C bindings for ffmpeg in GO.
- [go-astisub](go-astisub.md) — Manipulate subtitles in GO (.srt, .stl, .ttml, .webvtt, .ssa/.ass, teletext, .smi, etc.).
- [go-astits](go-astits.md) — Parse and demux MPEG Transport Streams (.ts) natively in GO.
- [go-mpd](go-mpd.md) — Parser and generator library for MPEG-DASH manifest files.
- [goav](goav.md) — Comprehensive Go bindings for FFmpeg.
- [gortsplib](gortsplib.md) — Pure Go RTSP server and client library.
- [hls-m3u8](hls-m3u8.md) — Parser and generator for HLS (M3U8) playlists; kept up to date with the spec.
- [libvlc-go](libvlc-go.md) — Go bindings for libvlc 2.X/3.X/4.X (used by the VLC media player).
- [manifestor](manifestor.md) — Zero-dependency library for parsing, filtering, transforming, and building HLS and DASH manifests.
- [mosaic](mosaic.md) — Predictable, production-ready Adaptive Bitrate (ABR) video packaging for Go (HLS & DASH CMAF).
- [mp4ff](mp4ff.md) — Library and tools for working with MP4 files containing video, audio, subtitles, or metadata.
- [mpeg-ts-analyzer](mpeg-ts-analyzer.md) — Analyzer for MPEG-2 Transport Streams that checks PCR timing compliance and dumps low-level TS, PSI, and PES structures.
- [onvif-go](onvif-go.md) — ONVIF client, WS-Discovery and virtual camera server for IP cameras.
- [rtspeek](rtspeek.md) — Library and CLI for probing RTSP streams and reporting reachability, latency, codecs, and resolutions.
- [v4l](v4l.md) — Video capture library for Linux, written in Go.
