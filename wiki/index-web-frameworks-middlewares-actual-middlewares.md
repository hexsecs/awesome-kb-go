# Web Frameworks / Middlewares / Actual middlewares

- [apitally](apitally.md) — API monitoring and analytics middleware with metrics, logging, and alerts. Works with Chi, Echo, Fiber, and Gin.
- [client-timing](client-timing.md) — An HTTP client for Server-Timing header.
- [CORS](cors.md) — Easily add CORS capabilities to your API.
- [echo-middleware](echo-middleware.md) — Middleware for Echo framework with logging and metrics.
- [formjson](formjson.md) — Transparently handle JSON input as a standard form POST.
- [go-fault](go-fault.md) — Fault injection middleware for Go.
- [Limiter](limiter.md) — Dead simple rate limit middleware for Go.
- [ln-paywall](ln-paywall.md) — Go middleware for monetizing APIs on a per-request basis with the Lightning Network (Bitcoin).
- [mid](mid.md) — Miscellaneous HTTP middleware features: idiomatic error return from handlers; receive/respond with JSON data; request tracing; and more.
- [rk-gin](rk-gin.md) — Middleware for Gin framework with logging, metrics, auth, tracing etc.
- [rk-grpc](rk-grpc.md) — Middleware for gRPC with logging, metrics, auth, tracing etc.
- [Tollbooth](tollbooth.md) — Rate limit HTTP request handler.
- [XFF](xff.md) — Handle X-Forwarded-For header and friends.
