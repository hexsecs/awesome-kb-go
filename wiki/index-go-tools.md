# Go Tools

- [decouple](decouple.md) — Find “overspecified” function parameters that could be generalized with interface types.
- [docs](docs.md) — Automatically generate RESTful API documentation for GO projects - aligned with Open API Specification standard.
- [go-callvis](go-callvis.md) — Visualize call graph of your Go program using dot format.
- [go-size-analyzer](go-size-analyzer.md) — Analyze and visualize the size of dependencies in compiled Golang binaries, providing insight into their impact on the final build.
- [go-swagger](go-swagger.md) — Swagger 2.0 implementation for go. Swagger is a simple yet powerful representation of your RESTful API.
- [go-template-playground](go-template-playground.md) — An interactive environment to create and test Go templates.
- [godbg](godbg.md) — Implementation of Rusts dbg! macro for quick and easy debugging during development.
- [gofindimpl](gofindimpl.md) — Find all structs that implement a given Go interface across a codebase.
- [gomodrun](gomodrun.md) — Go tool that executes and caches binaries included in go.mod files.
- [gotemplate.io](gotemplate-io.md) — Online tool to preview text/template templates live.
- [gotestdox](gotestdox.md) — Show Go test results as readable sentences.
- [gothanks](gothanks.md) — GoThanks automatically stars your go.mod github dependencies, sending this way some love to their maintainers.
- [gotutor](gotutor.md) — Online Go Debugger & Visualizer.
- [govisual](govisual.md) — Zero-config, pure-Go HTTP request visualizer & debugger for local Go web development.
- [igo](igo.md) — An igo to go transpiler (new language features for Go language!)
- [lensm](lensm.md) — Go assembly and source viewer.
- [modver](modver.md) — Compare two versions of a Go module to check the version-number change required (major, minor, or patchlevel), according to semver rules.
- [MoniGO](monigo.md) — A performance monitoring library for Go applications. It provides real-time insights into application performance! 🚀
- [OctoLinker](octolinker.md) — Navigate through go files efficiently with the OctoLinker browser extension for GitHub.
- [richgo](richgo.md) — Enrich go test outputs with text decorations.
- [roumon](roumon.md) — Monitor current state of all active goroutines via a command line interface.
- [rts](rts.md) — RTS: response to struct. Generates Go structs from server responses.
- [textra](textra.md) — Extract Go struct field names, types and tags for filtering and exporting.
- [typex](typex.md) — Examine Go types and their transitive dependencies, alternatively export results as TypeScript value objects (or types) declaration.
