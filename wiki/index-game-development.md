# Game Development

- [Ark](ark.md) — Archetype-based Entity Component System (ECS) for Go.
- [due](due.md) — Distributed game server framework with a modular component design, providing tcp, kcp, ws and quic gateways.
- [Ebitengine](ebitengine.md) — dead simple 2D game engine in Go.
- [ecs](ecs.md) — Build your own Game-Engine based on the Entity Component System concept in Golang.
- [engo](engo.md) — Engo is an open-source 2D game engine written in Go. It follows the Entity-Component-System paradigm.
- [fantasyname](fantasyname.md) — Fantasy names generator.
- [g3n](g3n.md) — Go 3D Game Engine.
- [go-astar](go-astar.md) — Go implementation of the A\ path finding algorithm.
- [go-sdl2](go-sdl2.md) — Go bindings for the Simple DirectMedia Layer.
- [go3d](go3d.md) — Performance oriented 2D/3D math package for Go.
- [gogpu](gogpu.md) — GPU application framework with windowing, input, and rendering built on WebGPU — reduces 480+ lines of GPU code to ~20, zero CGO (GoGPU ecosystem: gg, ui…
- [gogpu/wgpu](gogpu-wgpu.md) — Pure Go WebGPU implementation with Vulkan, DX12, and Metal backends, zero CGO (part of GoGPU ecosystem).
- [GOKe](goke.md) — Data-Oriented (DOD), archetype-based ECS engine utilizing an L1 cache-aligned chunked SoA layout for predictable, stepless memory growth and zero-allocation…
- [gonet](gonet.md) — Game server skeleton implemented with golang.
- [goworld](goworld.md) — Scalable game server engine, featuring space-entity framework and hot-swapping.
- [grid](grid.md) — Generic 2D grid with ray-casting, shadow-casting and path finding.
- [Leaf](leaf.md) — Lightweight game server framework.
- [nano](nano.md) — Lightweight, facility, high performance golang based game server framework.
- [Oak](oak.md) — Pure Go game engine.
- [Pi](pi.md) — Game engine for creating retro games for modern computers. Inspired by Pico-8 and powered by Ebitengine.
- [Pitaya](pitaya.md) — Scalable game server framework with clustering support and client libraries for iOS, Android, Unity and others through the C SDK.
- [Pixel](pixel.md) — Hand-crafted 2D game library in Go.
- [prototype](prototype.md) — Cross-platform (Windows/Linux/Mac) library for creating desktop games using a minimal API.
- [raylib-go](raylib-go.md) — Go bindings for raylib, a simple and easy-to-use library to learn videogames programming.
- [sceneCamera](scenecamera.md) — Camera movement and view/projection matrices for museum, FPS, RTS, and stereo rendering modes.
- [termloop](termloop.md) — Terminal-based game engine for Go, built on top of Termbox.
- [tile](tile.md) — Data-oriented and cache-friendly 2D Grid library (TileMap), includes pathfinding, observers and import/export.
