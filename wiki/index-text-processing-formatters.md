# Text Processing / Formatters

- [address](address.md) — Handles address representation, validation and formatting.
- [align](align.md) — A general purpose application that aligns text.
- [bytes](bytes.md) — Formats and parses numeric byte values (10K, 2M, 3G, etc.).
- [go-fixedwidth](go-fixedwidth.md) — Fixed-width text formatting (encoder/decoder with reflection).
- [go-humanize](go-humanize.md) — Formatters for time, numbers, and memory size to human readable format.
- [gotabulate](gotabulate.md) — Easily pretty-print your tabular data with Go.
- [sq](sq-2.md) — Convert data from SQL databases or document formats like CSV or Excel into formats such as JSON, Excel, CSV, HTML, Markdown, XML, and YAML.
- [textwrap](textwrap.md) — Wraps text at end of lines. Implementation of textwrap module from Python.
