# Database Drivers / Interfaces to Multiple Backends

- [cayley](cayley.md) — Graph database with support for multiple backends.
- [dsc](dsc.md) — Datastore connectivity for SQL, NoSQL, structured files.
- [dynamo](dynamo.md) — A simple key-value abstraction to store algebraic and linked-data data types at AWS storage services: AWS DynamoDB and AWS S3.
- [go-transaction-manager](go-transaction-manager.md) — Transaction manager with multiple adapters (sql, sqlx, gorm, mongo, ...) controls transaction boundaries.
- [gokv](gokv.md) — Simple key-value store abstraction and implementations for Go (Redis, Consul, etcd, bbolt, BadgerDB, LevelDB, Memcached, DynamoDB, S3, PostgreSQL, MongoDB…
- [transactor](transactor.md) — Type-safe transaction boundary abstraction with adapters for database/sql, sqlx, and pgx.
