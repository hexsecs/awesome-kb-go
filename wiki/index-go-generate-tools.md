# Go Generate Tools

- [envdoc](envdoc.md) — generate documentation for environment variables from Go source files.
- [generic](generic.md) — flexible data type for Go.
- [gocontracts](gocontracts.md) — brings design-by-contract to Go by synchronizing the code with the documentation.
- [godal](godal-2.md) — Generate orm models corresponding to golang by specifying sql ddl file, which can be used by gorm.
- [gonerics](gonerics.md) — Idiomatic Generics in Go.
- [gotests](gotests.md) — Generate Go tests from your source code.
- [gounit](gounit.md) — Generate Go tests using your own templates.
- [hasgo](hasgo.md) — Generate Haskell inspired functions for your slices.
- [oapixconstgen](oapixconstgen.md) — Generate typed Go constants from an OpenAPI spec's x-constants extension.
- [options-gen](options-gen.md) — Functional options described by Dave Cheney's post "Functional options for friendly APIs".
- [re2dfa](re2dfa.md) — Transform regular expressions into finite state machines and output Go source code.
- [sqlgen](sqlgen.md) — Generate gorm, xorm, sqlx, bun, sql code from SQL file or DSN.
- [TOML-to-Go](toml-to-go.md) — Translates TOML into a Go type in the browser instantly.
- [xgen](xgen.md) — XSD (XML Schema Definition) parser and Go/C/Java/Rust/TypeScript code generator.
