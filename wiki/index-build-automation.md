# Build Automation

- [1build](1build.md) — Command line tool to frictionlessly manage project-specific commands.
- [air](air.md) — Air - Live reload for Go apps.
- [anko](anko.md) — Simple application watcher for multiple programming languages.
- [gaper](gaper.md) — Builds and restarts a Go project when it crashes or some watched file changes.
- [gilbert](gilbert.md) — Build system and task runner for Go projects.
- [gob](gob.md) — Gradle/Maven like build tool for Go projects.
- [goyek](goyek.md) — Create build pipelines in Go.
- [mage](mage.md) — Mage is a make/rake-like build tool using Go.
- [mmake](mmake.md) — Modern Make.
- [realize](realize.md) — Go build a system with file watchers and live to reload. Run, build and watch file changes with custom paths.
- [rex](rex.md) — Zero-config universal project runner. Detects your stack (Go, Node, Python, Rust, PHP, Zig, Elixir) and runs the right command.
- [Task](task.md) — simple "Make" alternative.
- [taskctl](taskctl.md) — Concurrent task runner.
- [xc](xc.md) — Task runner with README.md defined tasks, executable markdown.
