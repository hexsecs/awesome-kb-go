# Bot Building

- [arikawa](arikawa.md) — A library and framework for the Discord API.
- [bot](bot.md) — Zero-dependencies Telegram Bot library with additional UI components.
- [echotron](echotron.md) — An elegant and concurrent library for Telegram Bots in Go.
- [go-joe](go-joe.md) — A general-purpose bot library inspired by Hubot but written in Go.
- [go-sarah](go-sarah.md) — Framework to build a bot for desired chat services including LINE, Slack, Gitter, and more.
- [go-tg](go-tg.md) — Generated from official docs Go client library for accessing Telegram Bot API, with batteries for building complex bots included.
- [go-twitch-irc](go-twitch-irc.md) — Library to write bots for twitch.tv chat
- [micha](micha.md) — Go Library for Telegram bot api.
- [slack-bot](slack-bot.md) — Ready to use Slack Bot for lazy developers: Custom commands, Jenkins, Jira, Bitbucket, Github...
- [slacker](slacker.md) — Easy to use framework to create Slack bots.
- [telebot](telebot.md) — Telegram bot framework is written in Go.
- [teleflow](teleflow.md) — Simple, type-safe Telegram bot framework with fluent flows and automatic state management.
- [telego](telego.md) — Telegram Bot API library for Golang with full one-to-one API implementation.
- [telegram-bot-api](telegram-bot-api.md) — Simple and clean Telegram bot client.
- [TG](tg.md) — Telegram Bot Framework for Go.
- [wayback](wayback.md) — A bot for Telegram, Mastodon, Slack, and other messaging platforms archives webpages.
- [Wisp](wisp.md) — Event-driven trading framework for Go. Spot, perpetual futures, prediction markets. Multi-exchange (Bybit, Hyperliquid, Polymarket).
- [ymsdk](ymsdk.md) — Go SDK for Yandex Messenger Bot API with type-safe models, automatic retry, and rate-limit handling.
