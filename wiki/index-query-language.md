# Query Language

- [api-fu](api-fu.md) — Comprehensive GraphQL implementation.
- [dasel](dasel.md) — Query and update data structures using selectors from the command line. Comparable to jq/yq but supports JSON, YAML, TOML and XML with zero runtime…
- [gnata](gnata.md) — Pure-Go implementation of the JSONata 2.x query and transformation language.
- [gojsonq](gojsonq.md) — A simple Go package to Query over JSON Data.
- [goven](goven.md) — A drop-in query language for any database schema.
- [gqlgen](gqlgen.md) — go generate based graphql server library.
- [grapher](grapher.md) — A GraphQL field builder utilizing Go generics with extra utilities and features.
- [graphql](graphql.md) — GraphQL server with a focus on ease of use.
- [graphql-go](graphql-go.md) — Implementation of GraphQL for Go.
- [gws](gws-2.md) — Apollos' "GraphQL over Websocket" client and server implementation.
- [jsonpath](jsonpath.md) — A query library for retrieving part of JSON based on JSONPath syntax.
- [jsonql](jsonql.md) — JSON query expression library in Golang.
- [jsonslice](jsonslice.md) — Jsonpath queries with advanced filters.
- [mql](mql.md) — Model Query Language (mql) is a query language for your database models.
- [play](play.md) — A TUI playground to experiment with your favorite programs, such as grep, sed, awk, jq and yq.
- [rql](rql.md) — Resource Query Language for REST API.
- [rqp](rqp.md) — Query Parser for REST API. Filtering, validations, both AND, OR operations are supported directly in the query.
- [straf](straf.md) — Easily Convert Golang structs to GraphQL objects.
