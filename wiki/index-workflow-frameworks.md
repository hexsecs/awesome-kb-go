# Workflow Frameworks

- [Cadence-client](cadence-client.md) — A framework for authoring workflows and activities running on top of the Cadence orchestration engine made by Uber.
- [Dagu](dagu.md) — No-code workflow executor. it executes DAGs defined in a simple YAML format.
- [durable-go](durable-go.md) — Durable execution engine for single-process Go apps and AI agents, with zero dependencies.
- [Flowbaker](flowbaker.md) — Self-hosted execution engine for building, connecting, and automating no-code workflows.
- [go-dag](go-dag.md) — A framework developed in Go that manages the execution of workflows described by directed acyclic graphs.
- [go-taskflow](go-taskflow.md) — A taskflow-like General-purpose Task-parallel Programming Framework with integrated visualizer and profiler.
- [GopherFlow](gopherflow.md) — Durable workflow engine with a built-in web console, backed by Postgres, MySQL or SQLite.
- [workflow](workflow.md) — A tech stack agnostic Event Driven Workflow framework.
