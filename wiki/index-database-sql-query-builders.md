# Database / SQL Query Builders

- [bqb](bqb.md) — Lightweight and easy to learn query builder.
- [buildsqlx](buildsqlx.md) — Go database query builder library for PostgreSQL.
- [builq](builq.md) — Easily build SQL queries in Go.
- [dba](dba.md) — SQL query builder for hand-written SQL, adding dynamic conditions, dialect-aware placeholders, and immutable chaining.
- [dbq](dbq.md) — Zero boilerplate database operations for Go.
- [Dotsql](dotsql.md) — Go library that helps you keep sql files in one place and use them with ease.
- [gendry](gendry.md) — Non-invasive SQL builder and powerful data binder.
- [godbal](godbal.md) — Database Abstraction Layer (dbal) for go. Support SQL builder and get result easily.
- [goqu](goqu.md) — Idiomatic SQL builder and query library.
- [gosql](gosql.md) — SQL Query builder with better null values support.
- [Hotcoal](hotcoal.md) — Secure your handcrafted SQL against injection.
- [igor](igor.md) — Abstraction layer for PostgreSQL that supports advanced functionality and uses gorm-like syntax.
- [jet](jet.md) — Framework for writing type-safe SQL queries in Go, with ability to easily convert database query result into desired arbitrary object structure.
- [obreron](obreron.md) — Fast and cheap SQL builder which does only one thing, SQL building.
- [ormlite](ormlite.md) — Lightweight package containing some ORM-like features and helpers for sqlite databases.
- [ozzo-dbx](ozzo-dbx.md) — Powerful data retrieval methods as well as DB-agnostic query building capabilities.
- [patcher](patcher.md) — Powerful SQL Query builder that automatically generates SQL queries from structs.
- [qrafter](qrafter.md) — Type-safe SQL query builder with dialect-aware rendering, schema introspection, and migration generation.
- [qry](qry.md) — Tool that generates constants from files with raw SQL queries.
- [relica](relica.md) — Type-safe database query builder with zero production dependencies, LRU statement cache, batch operations, and support for JOINs, subqueries, CTEs, and…
- [sg](sg.md) — A SQL Gen for generating standard SQLs(supports: CRUD) written in Go.
- [sq](sq.md) — Type-safe SQL builder and struct mapper for Go.
- [sqlc](sqlc.md) — Generate type-safe code from SQL.
- [sqlcredo](sqlcredo.md) — Package for type-safe generic SQL CRUD operations with pagination, transactions, debugging, and custom raw SQL extensions.
- [sqlf](sqlf.md) — Fast SQL query builder.
- [sqlh](sqlh.md) — Zero-boilerplate SQL helper with struct tags and Go generics (CRUD, UPSERT, JOIN, benchmarks).
- [sqlingo](sqlingo.md) — A lightweight DSL to build SQL in Go.
- [sqrl](sqrl.md) — SQL query builder, fork of Squirrel with improved performance.
- [Squalus](squalus.md) — Thin layer over the Go SQL package that makes it easier to perform queries.
- [Squirrel](squirrel.md) — Go library that helps you build SQL queries.
- [xo](xo.md) — Generate idiomatic Go code for databases based on existing schema definitions or custom queries supporting PostgreSQL, MySQL, SQLite, Oracle, and Microsoft…
