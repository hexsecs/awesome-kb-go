# Science and Data Analysis

- [bradleyterry](bradleyterry.md) — Provides a Bradley-Terry Model for pairwise comparisons.
- [calendarheatmap](calendarheatmap.md) — Calendar heatmap in plain Go inspired by Github contribution activity.
- [chart](chart.md) — Simple Chart Plotting library for Go. Supports many graphs types.
- [dataframe-go](dataframe-go.md) — Dataframes for machine-learning and statistics (similar to pandas).
- [decimal](decimal-5.md) — Package decimal implements arbitrary-precision decimal floating-point arithmetic.
- [entitydebs](entitydebs.md) — A social science tool to programmatically analyze entities in non-fictional texts with a built-in dependency parser.
- [evaler](evaler.md) — Simple floating point arithmetic expression evaluator.
- [ewma](ewma.md) — Exponentially-weighted moving averages.
- [geom](geom.md) — 2D geometry for golang.
- [go-dsp](go-dsp.md) — Digital Signal Processing for Go.
- [go-estimate](go-estimate.md) — State estimation and filtering algorithms in Go.
- [go-gt](go-gt.md) — Graph theory algorithms written in "Go" language.
- [go-hep](go-hep.md) — A set of libraries and tools for performing High Energy Physics analyses with ease.
- [godesim](godesim.md) — Extended/multivariable ODE solver framework for event-based simulations with simple API.
- [goent](goent.md) — GO Implementation of Entropy Measures.
- [gograph](gograph.md) — A golang generic graph library that provides mathematical graph-theory and algorithms.
- [gonum](gonum.md) — Gonum is a set of numeric libraries for the Go programming language. It contains libraries for matrices, statistics, optimization, and more.
- [gonum/plot](gonum-plot.md) — gonum/plot provides an API for building and drawing plots in Go.
- [goraph](goraph.md) — Pure Go graph theory library(data structure, algorithm visualization).
- [gosl](gosl.md) — Go scientific library for linear algebra, FFT, geometry, NURBS, numerical methods, probabilities, optimisation, differential equations, and more.
- [GoStats](gostats.md) — GoStats is an Open Source GoLang library for math statistics mostly used in Machine Learning domains, it covers most of the Statistical measures functions.
- [graph](graph.md) — Library of basic graph algorithms.
- [hdf5](hdf5.md) — Pure Go implementation of the HDF5 file format for scientific data storage and exchange.
- [insyra](insyra.md) — Data analysis library with statistics, visualization, Parquet support, and Python integration.
- [jsonl-graph](jsonl-graph.md) — Tool to manipulate JSONL graphs with graphviz support.
- [matlab](matlab.md) — Pure Go library for reading and writing MATLAB .mat files (v5-v7.3) without CGO.
- [MatProInterface.go](matprointerface-go.md) — MatProInterface.go is an open source package for defining mathematical programs (e.g., convex optimization problems) in Go.
- [ode](ode.md) — Ordinary differential equation (ODE) solver which supports extended states and channel-based iteration stop conditions.
- [orb](orb.md) — 2D geometry types with clipping, GeoJSON and Mapbox Vector Tile support.
- [pagerank](pagerank.md) — Weighted PageRank algorithm implemented in Go.
- [piecewiselinear](piecewiselinear.md) — Tiny linear interpolation library.
- [PiHex](pihex.md) — Implementation of the "Bailey-Borwein-Plouffe" algorithm for the hexadecimal number Pi.
- [Poly](poly.md) — A Go package for engineering organisms.
- [rootfinding](rootfinding.md) — root-finding algorithms library for finding roots of quadratic functions.
- [simd](simd.md) — Native Go vector and SIMD operations on slices with multi-architecture assembly acceleration.
- [sparse](sparse.md) — Go Sparse matrix formats for linear algebra supporting scientific and machine learning applications, compatible with gonum matrix libraries.
- [stats](stats-2.md) — Statistics package with common functions missing from the Golang standard library.
- [streamtools](streamtools.md) — general purpose, graphical tool for dealing with streams of data.
- [taxonkit](taxonkit.md) — A practical and efficient NCBI taxonomy toolkit; supports querying lineage, reformatting, filtering, and creating custom taxdump files.
- [TextRank](textrank.md) — TextRank implementation in Golang with extendable features (summarization, weighting, phrase extraction) and multithreading (goroutine) support.
- [topk](topk.md) — Sliding-window and regular top-K sketches, based on the HeavyKeeper algorithm.
- [triangolatte](triangolatte.md) — 2D triangulation library. Allows translating lines and polygons (both based on points) to the language of GPUs.
