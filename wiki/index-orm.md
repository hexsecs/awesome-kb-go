# ORM

- [bob](bob.md) — SQL query builder and ORM/Factory generator for Go. Successor of SQLBoiler.
- [bun](bun.md) — SQL-first Golang ORM. Successor of go-pg.
- [cacheme](cacheme.md) — Schema based, typed Redis caching/memoize framework for Go.
- [CQL](cql.md) — Built on top of GORM, adds compile-time verified queries based on auto-generated code.
- [ent](ent.md) — An entity framework for Go. Simple, yet powerful ORM for modeling and querying data.
- [go-dbw](go-dbw.md) — A simple package that encapsulates database operations.
- [go-firestorm](go-firestorm.md) — A simple ORM for Google/Firebase Cloud Firestore.
- [go-sql](go-sql.md) — A easy ORM for mysql.
- [go-sqlbuilder](go-sqlbuilder.md) — A flexible and powerful SQL string builder library plus a zero-config ORM.
- [go-store](go-store.md) — Simple and fast Redis backed key-value store library for Go.
- [golobby/orm](golobby-orm.md) — Simple, fast, type-safe, generic orm for developer happiness.
- [GoooQo](goooqo.md) — A database access framework based on declarative query model.
- [GORM](gorm.md) — The fantastic ORM library for Golang, aims to be developer friendly.
- [gormt](gormt.md) — Mysql database to golang gorm struct.
- [gorp](gorp.md) — Go Relational Persistence, ORM-ish library for Go.
- [grimoire](grimoire.md) — Grimoire is a database access layer and validation for golang. (Support: MySQL, PostgreSQL and SQLite3).
- [lore](lore.md) — Simple and lightweight pseudo-ORM/pseudo-struct-mapping environment for Go.
- [marlow](marlow.md) — Generated ORM from project structs for compile time safety assurances.
- [pop/soda](pop-soda.md) — Database migration, creation, ORM, etc... for MySQL, PostgreSQL, and SQLite.
- [Prisma](prisma.md) — Prisma Client Go, Typesafe database access for Go.
- [reform](reform.md) — Better ORM for Go, based on non-empty interfaces and code generation.
- [rel](rel.md) — Modern Database Access Layer for Golang - Testable, Extendable and Crafted Into a Clean and Elegant API.
- [SQLBoiler](sqlboiler.md) — ORM generator. Generate a featureful and blazing-fast ORM tailored to your database schema.
- [upper.io/db](upper-io-db.md) — Single interface for interacting with different data sources through the use of adapters that wrap mature database drivers.
- [XORM](xorm.md) — Simple and powerful ORM for Go. (Support: MySQL, MyMysql, PostgreSQL, Tidb, SQLite3, MsSql and Oracle).
- [Zoom](zoom.md) — Blazing-fast datastore and querying engine built on Redis.
