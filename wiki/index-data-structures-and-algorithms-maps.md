# Data Structures and Algorithms / Maps

- [cmap](cmap.md) — a thread-safe concurrent map for go, support using interface{} as key and auto scale up shards.
- [concurrent-swiss-map](concurrent-swiss-map.md) — A high-performance, thread-safe generic concurrent hash map implementation with Swiss Map.
- [dict](dict.md) — Python-like dictionaries (dict) for Go.
- [genericsyncmap](genericsyncmap.md) — Type-safe generic wrapper for sync.Map with full method parity and zero dependencies.
- [go-shelve](go-shelve.md) — A persistent, map-like object for the Go programming language. Supports multiple embedded key-value stores.
- [goradd/maps](goradd-maps.md) — Go 1.18+ generic map interface for maps; safe maps; ordered maps; ordered, safe maps; etc.
- [hmap](hmap.md) — HMap is a concurrent and secure, generic support Map implementation designed to provide an easy-to-use API.
