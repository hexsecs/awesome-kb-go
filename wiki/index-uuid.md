# UUID

- [fastuuid](fastuuid.md) — Fast generate UUIDv4 as string or bytes.
- [goid](goid.md) — Generate and Parse RFC4122 compliant V4 UUIDs.
- [gouid](gouid.md) — Generate cryptographically secure random string IDs with just one allocation.
- [guid](guid.md) — Fast cryptographically safe Guid generator for Go (~10x faster than uuid).
- [nanoid](nanoid.md) — A tiny and efficient Go unique string ID generator.
- [nanoid](nanoid-2.md) — Efficient, cryptographically secure generator for fast, concurrent NanoID and UUID creation.
- [sno](sno.md) — Compact, sortable and fast unique IDs with embedded metadata.
- [ulid](ulid.md) — Go implementation of ULID (Universally Unique Lexicographically Sortable Identifier).
- [uniq](uniq.md) — No hassle safe, fast unique identifiers with commands.
- [uuid](uuid.md) — Generate, encode, and decode UUIDs v1 with fast or cryptographic-quality random node identifier.
- [uuid](uuid-2.md) — Implementation of Universally Unique Identifier (UUID). Supports both creation and parsing of UUIDs. Actively maintained fork of satori uuid.
- [uuid](uuid-3.md) — Go package for UUIDs based on RFC 4122 and DCE 1.1: Authentication and Security Services.
- [uuidcheck](uuidcheck.md) — A tiny, dependency-free Go library that validates UUIDs against standard RFC 4122 formatting, converts UUIDv7() into UTC timestamps.
- [wuid](wuid.md) — An extremely fast globally unique number generator.
- [xid](xid.md) — Xid is a globally unique id generator library, ready to be safely used directly in your server code.
