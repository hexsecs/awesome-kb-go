# Web Frameworks / Routers

- [alien](alien.md) — Lightweight and fast http router from outer space.
- [bellt](bellt.md) — A simple Go HTTP router.
- [Bone](bone.md) — Lightning Fast HTTP Multiplexer.
- [Bxog](bxog.md) — Simple and fast HTTP router for Go. It works with routes of varying difficulty, length and nesting. And he knows how to create a URL from the received…
- [chi](chi.md) — Small, fast and expressive HTTP router built on net/context.
- [fasthttprouter](fasthttprouter.md) — High performance router forked from httprouter. The first router fit for fasthttp.
- [FastRouter](fastrouter.md) — a fast, flexible HTTP router written in Go.
- [Fox](fox.md) — A high-performance HTTP router for building reverse proxies and API gateways, with first-class support for mutating routes at runtime.
- [fursy](fursy.md) — HTTP router with type-safe generic handlers, automatic OpenAPI 3.1 generation from code, and RFC 9457 error responses.
- [goblin](goblin-2.md) — A golang http router based on trie tree.
- [gocraft/web](gocraft-web.md) — Mux and middleware package in Go.
- [Goji](goji.md) — Goji is a minimalistic and flexible HTTP request multiplexer with support for net/context.
- [GoLobby/Router](golobby-router.md) — GoLobby Router is a lightweight yet powerful HTTP router for the Go programming language.
- [goroute](goroute.md) — Simple yet powerful HTTP request multiplexer.
- [GoRouter](gorouter.md) — GoRouter is a Server/API micro framework, HTTP request router, multiplexer, mux that provides request router with middleware supporting net/context.
- [gowww/router](gowww-router.md) — Lightning fast HTTP router fully compatible with the net/http.Handler interface.
- [httprouter](httprouter.md) — High performance router. Use this and the standard http handlers to form a very high performance web framework.
- [httptreemux](httptreemux.md) — High-speed, flexible tree-based HTTP router for Go. Inspiration from httprouter.
- [lars](lars.md) — Is a lightweight, fast and extensible zero allocation HTTP router for Go used to create customizable frameworks.
- [mux](mux.md) — Powerful URL router and dispatcher for golang.
- [nchi](nchi.md) — chi-like router built on httprouter with dependency injection based middleware wrappers
- [ngamux](ngamux.md) — Simple HTTP router for Go.
- [ozzo-routing](ozzo-routing.md) — An extremely fast Go (golang) HTTP router that supports regular expression route matching. Comes with full support for building RESTful APIs.
- [pure](pure.md) — Is a lightweight HTTP router that sticks to the std "net/http" implementation.
- [Siesta](siesta.md) — Composable framework to write middleware and handlers.
- [vestigo](vestigo.md) — Performant, stand-alone, HTTP compliant URL Router for go web applications.
- [violetear](violetear.md) — Go HTTP router.
- [xmux](xmux.md) — High performance muxer based on httprouter with net/context support.
- [xujiajun/gorouter](xujiajun-gorouter.md) — A simple and fast HTTP router for Go.
