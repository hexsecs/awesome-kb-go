# Natural Language Processing / Translation

- [ctxi18n](ctxi18n.md) — Context aware i18n with a short and consise API, pluralization, interpolation, and fs.FS support. YAML locale definitions are based on Rails i18n.
- [go-i18n](go-i18n.md) — Package and an accompanying tool to work with localized text.
- [go-mystem](go-mystem.md) — CGo bindings to Yandex.Mystem - russian morphology analyzer.
- [go-pinyin](go-pinyin.md) — CN Hanzi to Hanyu Pinyin converter.
- [go-words](go-words.md) — A words table and text resource library for Golang projects.
- [gotext](gotext.md) — GNU gettext utilities for Go.
- [iuliia-go](iuliia-go.md) — Transliterate Cyrillic → Latin in every possible way.
- [spreak](spreak.md) — Flexible translation and humanization library for Go, based on the concepts behind gettext.
- [t](t.md) — Another i18n pkg for golang, which follows GNU gettext style and supports .po/.mo files: t.T (gettext), t.N (ngettext), etc. And it contains a cmd tool…
