# Text Processing / Regular Expressions

- [coregex](coregex.md) — Production regex engine with Rust regex-crate architecture: multi-engine DFA/NFA, SIMD prefilters, drop-in stdlib replacement.
- [genex](genex.md) — Count and expand Regular Expressions into all matching Strings.
- [go-wildcard](go-wildcard.md) — Simple and lightweight wildcard pattern matching.
- [goregen](goregen.md) — Library for generating random strings from regular expressions.
- [regroup](regroup.md) — Match regex expression named groups into go struct using struct tags and automatic parsing.
- [rex](rex-2.md) — Regular expressions builder.
