# Windows

- [d3d9](d3d9.md) — Go bindings for Direct3D9.
- [go-ole](go-ole.md) — Win32 OLE implementation for golang.
- [gosddl](gosddl.md) — Converter from SDDL-string to user-friendly JSON. SDDL consist of four part: Owner, Primary Group, DACL, SACL.
- [windowsupdate](windowsupdate.md) — A Golang binding for Windows Update Agent API using go-ole.
