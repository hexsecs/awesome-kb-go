# Database / Database Schema Migration

- [atlas](atlas.md) — A Database Toolkit. A CLI designed to help companies better work with their data.
- [avro](avro.md) — Discover SQL schemas and convert them to AVRO schemas. Query SQL records into AVRO bytes.
- [bytebase](bytebase.md) — Safe database schema change and version control for DevOps teams.
- [darwin](darwin.md) — Database schema evolution library for Go.
- [db-migrator.go](db-migrator-go.md) — CLI for versioned database schema migrations with support for PostgreSQL, MySQL, ClickHouse, Tarantool, and Apache Iceberg.
- [dbmate](dbmate.md) — A lightweight, framework-agnostic database migration tool.
- [go-fixtures](go-fixtures.md) — Django style fixtures for Golang's excellent built-in database/sql library.
- [go-pg-migrate](go-pg-migrate.md) — CLI-friendly package for go-pg migrations management.
- [go-pg-migrations](go-pg-migrations.md) — A Go package to help write migrations with go-pg/pg.
- [goavro](goavro.md) — A Go package that encodes and decodes Avro data.
- [godfish](godfish.md) — Database migration manager, works with native query language. Support for cassandra, mysql, postgres, sqlite3.
- [goose](goose.md) — Database migration tool. You can manage your database's evolution by creating incremental SQL or Go scripts.
- [gorm-seeder](gorm-seeder.md) — Simple database seeder for Gorm ORM.
- [gormigrate](gormigrate.md) — Database schema migration helper for Gorm ORM.
- [libschema](libschema.md) — Define your migrations separately in each library. Migrations for open source libraries. MySQL & PostgreSQL.
- [migrate](migrate.md) — Database migrations. CLI and Golang library.
- [migrator](migrator.md) — Dead simple Go database migration library.
- [migrator](migrator-2.md) — MySQL database migrator designed to run migrations to your features and manage database schema update with intuitive go code.
- [schema](schema.md) — Library to embed schema migrations for database/sql-compatible databases inside your Go binaries.
- [skeema](skeema.md) — Pure-SQL schema management system for MySQL, with support for sharding and external online schema change tools.
- [soda](soda.md) — Database migration, creation, ORM, etc... for MySQL, PostgreSQL, and SQLite.
- [sql-migrate](sql-migrate.md) — Database migration tool. Allows embedding migrations into the application using go-bindata.
- [sqlize](sqlize.md) — Database migration generator. Allows generate sql migration from model and existing sql by differ them.
