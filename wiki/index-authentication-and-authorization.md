# Authentication and Authorization

- [authgate](authgate.md) — A lightweight OAuth 2.0 Authorization Server supporting Device Authorization Grant (RFC 8628), Authorization Code Flow with PKCE (RFC 6749 + RFC 7636), and…
- [branca](branca.md) — branca token specification implementation for Golang 1.15+.
- [casbin](casbin.md) — Authorization library that supports access control models like ACL, RBAC, and ABAC.
- [cookiestxt](cookiestxt.md) — provides a parser of cookies.txt file format.
- [go-githubauth](go-githubauth.md) — Utilities for GitHub authentication: generate and use GitHub application and installation tokens.
- [go-guardian](go-guardian.md) — Go-Guardian is a golang library that provides a simple, clean, and idiomatic way to create powerful modern API and web authentication that supports LDAP…
- [go-iam](go-iam.md) — Developer-first Identity and Access Management system with a simple UI.
- [go-jose](go-jose.md) — Fairly complete implementation of the JOSE working group's JSON Web Token, JSON Web Signatures, and JSON Web Encryption specs.
- [go-jwt](go-jwt.md) — A JWT (JSON Web Token) library for Go.
- [go-jwt](go-jwt-2.md) — JWT authentication package providing access tokens and refresh tokens with fingerprinting, Redis storage, and automatic refresh capabilities.
- [goiabada](goiabada.md) — An open-source authentication and authorization server supporting OAuth2 and OpenID Connect.
- [gologin](gologin.md) — chainable handlers for login with OAuth1 and OAuth2 authentication providers.
- [gorbac](gorbac.md) — provides a lightweight role-based access control (RBAC) implementation in Golang.
- [gosession](gosession.md) — This is quick session for net/http in GoLang. This package is perhaps the best implementation of the session mechanism, or at least it tries to become one.
- [goth](goth.md) — provides a simple, clean, and idiomatic way to use OAuth and OAuth2. Handles multiple providers out of the box.
- [jeff](jeff.md) — Simple, flexible, secure, and idiomatic web session management with pluggable backends.
- [jwt](jwt.md) — Lightweight JSON Web Token (JWT) library.
- [jwt](jwt-2.md) — Safe, simple, and fast JSON Web Tokens for Go.
- [jwt-auth](jwt-auth.md) — JWT middleware for Golang http servers with many configuration options.
- [jwt-go](jwt-go.md) — A full featured implementation of JSON Web Tokens (JWT). This library supports the parsing and verification as well as the generation and signing of JWTs.
- [jwx](jwx.md) — Go module implementing various JWx (JWA/JWE/JWK/JWS/JWT, otherwise known as JOSE) technologies.
- [keto](keto.md) — Open Source (Go) implementation of "Zanzibar: Google's Consistent, Global Authorization System". Ships gRPC, REST APIs, newSQL, and an easy and granular…
- [loginsrv](loginsrv.md) — JWT login microservice with pluggable backends such as OAuth2 (Github), htpasswd, osiam.
- [melange](melange.md) — Compiles OpenFGA authorization schemas into PL/pgSQL functions that run fine-grained relationship-based access control checks inside PostgreSQL.
- [oauth2](oauth2.md) — Successor of goauth2. Generic OAuth 2.0 package that comes with JWT, Google APIs, Compute Engine, and App Engine support.
- [oidc](oidc.md) — Easy to use OpenID Connect client and server library written for Go and certified by the OpenID Foundation.
- [openfga](openfga.md) — Implementation of fine-grained authorization based on the "Zanzibar: Google's Consistent, Global Authorization System" paper. Backed by CNCF.
- [osin](osin.md) — Golang OAuth2 server library.
- [otpgen](otpgen.md) — Library to generate TOTP/HOTP codes.
- [otpgo](otpgo.md) — Time-Based One-Time Password (TOTP) and HMAC-Based One-Time Password (HOTP) library for Go.
- [paseto](paseto.md) — Golang implementation of Platform-Agnostic Security Tokens (PASETO).
- [permissions](permissions.md) — Library for keeping track of users, login states, and permissions. Uses secure cookies and bcrypt.
- [scope](scope.md) — Easily Manage OAuth2 Scopes In Go.
- [scs](scs.md) — Session Manager for HTTP servers.
- [securecookie](securecookie.md) — Efficient secure cookie encoding/decoding.
- [session](session.md) — Go session management for web servers (including support for Google App Engine - GAE).
- [sessions](sessions.md) — Dead simple, highly performant, highly customizable sessions service for go http servers.
- [sessionup](sessionup.md) — Simple, yet effective HTTP session management and identification package.
- [sjwt](sjwt.md) — Simple jwt generator and parser.
- [spicedb](spicedb.md) — A Zanzibar-inspired database that enables fine-grained authorization.
- [x509proxy](x509proxy.md) — Library to handle X509 proxy certificates.
