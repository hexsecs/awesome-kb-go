# Date and Time

- [approx](approx.md) — A Duration extension supporting parsing/printing durations in days, weeks and years.
- [carbon](carbon.md) — A simple, semantic and developer-friendly time package for golang.
- [carbon](carbon-2.md) — Simple Time extension with a lot of util methods, ported from PHP Carbon library.
- [cronrange](cronrange.md) — Parses Cron-style time range expressions, checks if the given time is within any ranges.
- [date](date.md) — Augments Time for working with dates, date ranges, time spans, periods, and time-of-day.
- [dateparse](dateparse.md) — Parse date's without knowing format in advance.
- [durafmt](durafmt.md) — Time duration formatting library for Go.
- [feiertage](feiertage.md) — Set of functions to calculate public holidays in Germany, incl. specialization on the states of Germany (Bundesländer). Things like Easter, Pentecost…
- [go-anytime](go-anytime.md) — Parse dates/times like "next dec 22nd at 3pm" and ranges like "from today until next thursday" without knowing the format in advance.
- [go-date-fns](go-date-fns.md) — A comprehensive date utility library for Go, inspired by date-fns, with 140+ pure and immutable functions.
- [go-datebin](go-datebin.md) — A simple datetime parse pkg.
- [go-faketime](go-faketime.md) — A simple time.Now() that honors the faketime(1) utility.
- [go-persian-calendar](go-persian-calendar.md) — The implementation of the Persian (Solar Hijri) Calendar in Go (golang).
- [go-str2duration](go-str2duration.md) — Convert string to duration. Support time.Duration returned string and more.
- [go-sunrise](go-sunrise.md) — Calculate the sunrise and sunset times for a given location.
- [go-week](go-week.md) — An efficient package to work with ISO8601 week dates.
- [gostradamus](gostradamus.md) — A Go package for working with dates.
- [iso8601](iso8601.md) — Efficiently parse ISO8601 date-times without regex.
- [kair](kair.md) — Date and Time - Golang Formatting Library.
- [now](now.md) — Now is a time toolkit for golang.
- [strftime](strftime.md) — C99-compatible strftime formatter.
- [timespan](timespan.md) — For interacting with intervals of time, defined as a start time and a duration.
- [timeutil](timeutil.md) — Useful extensions (Timedelta, Strftime, ...) to the golang's time package.
- [timex](timex.md) — A Go package that extends the standard library time with dedicated date and time-of-day types.
- [tuesday](tuesday.md) — Ruby-compatible Strftime function.
