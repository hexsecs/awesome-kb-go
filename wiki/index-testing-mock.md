# Testing / Mock

- [counterfeiter](counterfeiter.md) — Tool for generating self-contained mock objects.
- [fabricator](fabricator.md) — Type-safe factories for generating mock and fake data in Go, inspired by factoryboy and interface-forge.
- [genmock](genmock.md) — Go mocking system with code generator for building calls of the interface methods.
- [go-localstack](go-localstack.md) — Tool for using localstack in AWS testing.
- [go-sqlmock](go-sqlmock.md) — Mock SQL driver for testing database interactions.
- [go-txdb](go-txdb.md) — Single transaction based database driver mainly for testing purposes.
- [gomock](gomock.md) — Mocking framework for the Go programming language.
- [gomock](gomock-2.md) — CLI tool to generate typed and framework-agnostic interface mocks, with support for generics.
- [gomocker](gomocker.md) — A live mocker library for functions and methods in Golang for unit testing with fluent syntax, no code-gen needed.
- [govcr](govcr.md) — HTTP mock for Golang: record and replay HTTP interactions for offline testing.
- [hoverfly](hoverfly.md) — HTTP(S) proxy for recording and simulating REST/SOAP APIs with extensible middleware and easy-to-use CLI.
- [httpmock](httpmock.md) — Easy mocking of HTTP responses from external resources.
- [minimock](minimock.md) — Mock generator for Go interfaces.
- [mockery](mockery.md) — Tool to generate Go interfaces.
- [mockfs](mockfs.md) — Mock filesystem for Go testing with error injection and latency simulation, built on testing/fstest.MapFS.
- [mockhttp](mockhttp.md) — Mock object for Go http.ResponseWriter.
- [mooncake](mooncake.md) — A simple way to generate mocks for multiple purposes.
- [moq](moq.md) — Utility that generates a struct from any interface. The struct can be used in test code as a mock of the interface.
- [moxie](moxie.md) — Generate mock methods on embedded structs.
- [pgxmock](pgxmock.md) — A mock library implementing pgx - PostgreSQL Driver and Toolkit.
- [timex](timex-2.md) — A test-friendly replacement for the native time package.
- [wsmock](wsmock.md) — Expressive, zero-boilerplate WebSocket mock server for testing with fault injection and assertions.
- [xgo](xgo.md) — A general pureposed function mocking library.
