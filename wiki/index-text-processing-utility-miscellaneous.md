# Text Processing / Utility/Miscellaneous

- [ahocorasick](ahocorasick.md) — High-performance Aho-Corasick multi-pattern string matching with DFA compilation and SIMD prefilter, up to 7 GB/s throughput (part of coregx ecosystem).
- [go-runewidth](go-runewidth.md) — Functions to get fixed width of the character or string.
- [kace](kace.md) — Common case conversions covering common initialisms.
- [lancet](lancet.md) — A comprehensive, Lodash-like utility library for Go
- [petrovich](petrovich.md) — Petrovich is the library which inflects Russian names to given grammatical case.
- [radix](radix.md) — Fast string sorting algorithm.
- [TySug](tysug.md) — Alternative suggestions with respect to keyboard layouts.
- [uniwidth](uniwidth.md) — High-performance Unicode character width calculation with SWAR optimization, O(1) lookup tables, and ZWJ emoji support.
- [w2vgrep](w2vgrep.md) — A semantic grep tool using word embeddings to find semantically similar matches. For example, searching for "death" will find "dead", "killing", "murder".
