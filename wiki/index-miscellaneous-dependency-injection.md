# Miscellaneous / Dependency Injection

- [alice](alice.md) — Additive dependency injection container for Golang.
- [autowire](autowire.md) — Dependency injection using Generics and reflection.
- [boot-go](boot-go.md) — Component-based development with dependency injection using reflections for Go developers.
- [componego](componego.md) — A dependency injection framework based on components, allowing dynamic dependency replacement without duplicating code in tests.
- [cosban/di](cosban-di.md) — A code generation based dependency injection wiring tool.
- [dig](dig.md) — A reflection based dependency injection toolkit for Go.
- [dingo](dingo.md) — A dependency injection toolkit for Go, based on Guice.
- [do](do.md) — A dependency injection framework based on Generics.
- [floatdrop/di](floatdrop-di.md) — Dependency injection container built on generic methods, with child scopes, lifecycle hooks and graph validation before anything is built.
- [fx](fx-2.md) — A dependency injection based application framework for Go (built on top of dig).
- [go-beans](go-beans.md) — Spring-inspired dependency injection and application lifecycle framework for Go.
- [Go-Spring](go-spring.md) — A high-performance Go framework inspired by Spring Boot, offering DI, auto-configuration, and lifecycle management while maintaining Go's simplicity and…
- [gocontainer](gocontainer.md) — Simple Dependency Injection Container.
- [godi](godi.md) — Microsoft-style dependency injection for Go with scoped lifetimes and generics.
- [goioc/di](goioc-di.md) — Spring-inspired Dependency Injection Container.
- [GoLobby/Container](golobby-container.md) — GoLobby Container is a lightweight yet powerful IoC dependency injection container for the Go programming language.
- [gontainer](gontainer.md) — A dependency injection service container for Go projects.
- [gontainer/gontainer](gontainer-gontainer.md) — A YAML-based Dependency Injection container for GO. It supports dependencies' scopes, and auto-detection of circular dependencies. Gontainer is concurrent-safe.
- [HnH/di](hnh-di.md) — DI container library that is focused on clean API and flexibility.
- [kinit](kinit.md) — Customizable dependency injection container with the global mode, cascade initialization and panic-safe finalization.
- [kod](kod.md) — A generics based dependency injection framework for Go.
- [linker](linker.md) — A reflection based dependency injection and inversion of control library with components lifecycle support.
- [nject](nject.md) — A type safe, reflective framework for libraries, tests, http endpoints, and service startup.
- [ore](ore.md) — Lightweight, generic & simple dependency injection (DI) container.
- [parsley](parsley.md) — A flexible and modular reflection-based DI library with advanced features like scoped contexts and proxy generation, designed for large-scale Go applications.
- [wire](wire.md) — Strict Runtime Dependency Injection for Golang.
- [yama](yama.md) — Compile-time dependency injection and lifecycle framework that generates start, quiesce, and stop code for Google Wire graphs.
