# Natural Language Processing / Transliteration

- [enca](enca.md) — Minimal cgo bindings for libenca, which detects character encodings.
- [go-unidecode](go-unidecode.md) — ASCII transliterations of Unicode text.
- [gounidecode](gounidecode.md) — Unicode transliterator (also known as unidecode) for Go.
- [transliterator](transliterator.md) — Provides one-way string transliteration with supporting of language-specific transliteration rules.
