# Benchmarks

- [autobench](autobench.md) — Framework to compare the performance between different Go versions.
- [go-benchmark-app](go-benchmark-app.md) — Powerful HTTP-benchmark tool mixed with Аb, Wrk, Siege tools. Gathering statistics and various parameters for benchmarks and comparison results.
- [go-benchmarks](go-benchmarks.md) — Few miscellaneous Go microbenchmarks. Compare some language features to alternative approaches.
- [go-http-routing-benchmark](go-http-routing-benchmark.md) — Go HTTP request router benchmark and comparison.
- [go-json-benchmark](go-json-benchmark.md) — Go JSON benchmark.
- [go-ml-benchmarks](go-ml-benchmarks.md) — benchmarks for machine learning inference in Go.
- [go-web-framework-benchmark](go-web-framework-benchmark.md) — Go web framework benchmark.
- [go_serialization_benchmarks](go-serialization-benchmarks.md) — Benchmarks of Go serialization methods.
- [gocostmodel](gocostmodel.md) — Benchmarks of common basic operations for the Go language.
- [golang-benchmarks](golang-benchmarks.md) — a collection of golang benchmarks.
- [gospeed](gospeed.md) — Go micro-benchmarks for calculating the speed of language constructs.
- [kvbench](kvbench.md) — Key/Value database benchmark.
- [skynet](skynet.md) — Skynet 1M threads microbenchmark.
- [speedtest-resize](speedtest-resize.md) — Compare various Image resize algorithms for the Go language.
- [vizb](vizb.md) — A CLI tool to visualize Go benchmark data in 4D.
