# XML

- [XML-Comp](xml-comp.md) — Simple command line XML comparer that generates diffs of folders, files and tags.
- [xml2map](xml2map.md) — XML to MAP converter written Golang.
- [xmlquery](xmlquery.md) — xmlquery is Golang XPath package for XML query.
- [xmlwriter](xmlwriter.md) — Procedural XML generation API based on libxml2's xmlwriter module.
- [xpath](xpath.md) — XPath package for Go.
- [zek](zek.md) — Generate a Go struct from XML.
