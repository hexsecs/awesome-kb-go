# Text Processing / Scrapers

- [colly](colly.md) — Fast and Elegant Scraping Framework for Gophers.
- [dataflowkit](dataflowkit.md) — Web scraping Framework to turn websites into structured data.
- [doc-scraper](doc-scraper.md) — Web crawler that converts documentation sites to clean Markdown and JSONL for LLM ingestion (RAG, training data).
- [go-recipe](go-recipe.md) — A package for scraping recipes from websites.
- [go-sitemap-parser](go-sitemap-parser.md) — Go language library for parsing Sitemaps.
- [GoQuery](goquery.md) — GoQuery brings a syntax and a set of features similar to jQuery to the Go language.
- [pagser](pagser.md) — Pagser is a simple, extensible, configurable parse and deserialize html page to struct based on goquery and struct tags for golang crawler.
- [Tagify](tagify.md) — Produces a set of tags from given source.
- [walker](walker.md) — Seamlessly fetch paginated data from any source. Simple and high performance API scraping included.
- [xurls](xurls.md) — Extract urls from text.
