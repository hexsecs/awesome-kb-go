# Natural Language Processing / Morphological Analyzers

- [go-propisyu](go-propisyu.md) — Convert numbers to Russian words with correct grammatical gender and noun declension.
- [go-stem](go-stem.md) — Implementation of the porter stemming algorithm.
- [go2vec](go2vec.md) — Reader and utility functions for word2vec embeddings.
- [golibstemmer](golibstemmer.md) — Go bindings for the snowball libstemmer library including porter 2.
- [gosentiwordnet](gosentiwordnet.md) — Sentiment analyzer using sentiwordnet lexicon in Go.
- [govader](govader.md) — Go implementation of VADER Sentiment Analysis.
- [govader-backend](govader-backend.md) — Microservice implementation of GoVader.
- [kagome](kagome.md) — JP morphological analyzer written in pure Go.
- [libtextcat](libtextcat.md) — Cgo binding for libtextcat C library. Guaranteed compatibility with version 2.2.
- [nlp](nlp.md) — Go Natural Language Processing library supporting LSA (Latent Semantic Analysis).
- [paicehusk](paicehusk.md) — Golang implementation of the Paice/Husk Stemming Algorithm.
- [porter](porter.md) — This is a fairly straightforward port of Martin Porter's C implementation of the Porter stemming algorithm.
- [porter2](porter2.md) — Really fast Porter 2 stemmer.
- [RAKE.go](rake-go.md) — Go port of the Rapid Automatic Keyword Extraction Algorithm (RAKE).
- [snowball](snowball.md) — Snowball stemmer port (cgo wrapper) for Go. Provides word stem extraction functionality Snowball native.
- [spaGO](spago.md) — Self-contained Machine Learning and Natural Language Processing library in Go.
- [spelling-corrector](spelling-corrector.md) — A spelling corrector for the Spanish language or create your own.
