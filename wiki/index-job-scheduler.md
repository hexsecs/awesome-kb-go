# Job Scheduler

- [cdule](cdule.md) — Job scheduler library with database support
- [cheek](cheek.md) — A simple crontab like scheduler that aims to offer a KISS approach to job scheduling.
- [clockwerk](clockwerk.md) — Go package to schedule periodic jobs using a simple, fluent syntax.
- [cronticker](cronticker.md) — A ticker implementation to support cron schedules.
- [go-cron](go-cron.md) — Simple Cron library for go that can execute closures or functions at varying intervals, from once a second to once a year on a specific date and time.…
- [go-cron](go-cron-2.md) — Cron job scheduler with runtime schedule updates, per-entry context, resilience middleware (retry, circuit breaker, rate limiting), and observability hooks…
- [go-job](go-job.md) — A flexible and extensible job scheduling and execution library for Go.
- [go-quartz](go-quartz.md) — Simple, zero-dependency scheduling library for Go.
- [go-scheduler](go-scheduler.md) — Job scheduler supporting standard cron expressions, custom descriptors, intervals, and task dependencies.
- [gocron](gocron.md) — Easy and fluent Go job scheduling. This is an actively maintained fork of jasonlvhit/gocron.
- [goflow](goflow.md) — A simple but powerful DAG scheduler and dashboard.
- [gron](gron.md) — Define time-based tasks using a simple Go API and Gron’s scheduler will run them accordingly.
- [gronx](gronx.md) — Cron expression parser, task runner and daemon consuming crontab like task list.
- [JobRunner](jobrunner.md) — Smart and featureful cron job scheduler with job queuing and live monitoring built in.
- [leprechaun](leprechaun.md) — Job scheduler that supports webhooks, crons and classic scheduling.
- [ofelia](ofelia.md) — Docker job scheduler (crontab for Docker); fork of mcuadros/ofelia that adds a web UI, job dependencies, retries, and job persistence.
- [pending](pending.md) — ID-based debounced task scheduler for deferred tasks with cancellation, graceful shutdown, and optional concurrency limits.
- [RunWisp](runwisp.md) — Single-binary replacement for cron and supervisord that keeps the exit code and output of every run, with a web UI and a TUI.
- [sched](sched.md) — A job scheduler with the ability to fast-forward time.
- [scheduler](scheduler.md) — Cronjobs scheduling made easy.
- [scheduler](scheduler-2.md) — Go-native distributed job scheduler with delayed tasks, batched Redis coordination, retries, lease-based recovery, and versioned queue partitioning.
- [tasks](tasks.md) — An easy to use in-process scheduler for recurring tasks in Go.
- [tickstem/cron](tickstem-cron.md) — Go client for scheduling HTTP cron jobs, with execution history, failure alerts, and tsk-local for testing handlers without live credentials.
- [tickstem/heartbeat](tickstem-heartbeat.md) — Go client for dead-man's switch heartbeat monitoring: ping a URL after each job run and get alerted by email if pings stop arriving.
