# Stream Processing

- [go-etl](go-etl.md) — A lightweight toolkit for data source extraction, transformation, and loading (ETL).
- [go-streams](go-streams.md) — Go stream processing library.
- [goio](goio.md) — An implementation of IO, Stream, Fiber for Golang, inspired by awesome Scala libraries cats and fs2.
- [gostream](gostream.md) — Type-safe stream processing library inspired by the Java Streams API.
- [machine](machine.md) — Go library for writing and generating stream workers with built in metrics and traceability.
- [nibbler](nibbler.md) — A lightweight package for micro batch processing.
- [ro](ro.md) — Reactive Programming: declarative and composable API for event-driven applications.
- [signals](signals.md) — Type-safe reactive state management inspired by Angular Signals with computed values, effects, and dependency tracking.
- [stream](stream.md) — Go Stream, like Java 8 Stream: Filter/Map/FlatMap/Peek/Sorted/ForEach/Reduce...
- [StreamSQL](streamsql.md) — A lightweight streaming SQL engine for real-time data processing.
