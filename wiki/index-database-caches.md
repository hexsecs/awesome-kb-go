# Database / Caches

- [bcache](bcache.md) — Eventually consistent distributed in-memory cache Go library.
- [BigCache](bigcache.md) — Efficient key/value cache for gigabytes of data.
- [cache2go](cache2go.md) — In-memory key:value cache which supports automatic invalidation based on timeouts.
- [cachego](cachego.md) — Golang Cache component for multiple drivers.
- [clusteredBigCache](clusteredbigcache.md) — BigCache with clustering support and individual item expiration.
- [coherence-go-client](coherence-go-client.md) — Full implementation of Oracle Coherence cache API for Go applications using gRPC as network transport.
- [couchcache](couchcache.md) — RESTful caching micro-service backed by Couchbase server.
- [easycache](easycache.md) — A simple way to use in-memory cache in Golang (TTL/FIFO/LRU/LFU).
- [EchoVault](echovault.md) — Embeddable Distributed in-memory data store compatible with Redis clients.
- [fastcache](fastcache.md) — fast thread-safe inmemory cache for big number of entries. Minimizes GC overhead.
- [GCache](gcache.md) — Cache library with support for expirable Cache, LFU, LRU and ARC.
- [gdcache](gdcache.md) — A pure non-intrusive cache library implemented by golang, you can use it to implement your own distributed cache.
- [go-cache](go-cache.md) — A flexible multi-layer Go caching library to deal with in-memory and shared cache by adopting Cache-Aside pattern.
- [go-freelru](go-freelru.md) — A GC-less, fast and generic LRU hashmap library with optional locking, sharding, eviction and expiration.
- [go-gcache](go-gcache.md) — The generic version of GCache, cache support for expirable Cache, LFU, LRU and ARC.
- [go-mcache](go-mcache.md) — Fast in-memory key:value store/cache library. Pointer caches.
- [gocache](gocache.md) — A complete Go cache library with multiple stores (memory, memcache, redis, ...), chainable, loadable, metrics cache and more.
- [gocache](gocache-2.md) — A data race free Go ache library with high performance and auto pruge functionality
- [groupcache](groupcache.md) — Groupcache is a caching and cache-filling library, intended as a replacement for memcached in many cases.
- [icache](icache.md) — A High Performance, Generic, thread-safe, zero-dependency cache package.
- [imcache](imcache.md) — A generic in-memory cache Go library. It supports expiration, sliding expiration, max entries limit, eviction callbacks and sharding.
- [jetcache-go](jetcache-go.md) — Unified Go cache library supporting multi-level caching.
- [nscache](nscache.md) — A Go caching framework that supports multiple data source drivers.
- [otter](otter.md) — A high performance lockless cache for Go. Many times faster than Ristretto and friends.
- [pocache](pocache.md) — Pocache is a minimal cache package which focuses on a preemptive optimistic caching strategy.
- [ristretto](ristretto.md) — A high performance memory-bound Go cache.
- [sturdyc](sturdyc.md) — A caching library with advanced concurrency features designed to make I/O heavy applications robust and highly performant.
- [theine](theine.md) — High performance, near optimal in-memory cache with proactive TTL expiration and generics.
- [timedmap](timedmap.md) — Map with expiring key-value pairs.
- [ttlcache](ttlcache.md) — An in-memory cache with item expiration and generics.
- [ttlcache](ttlcache-2.md) — In-memory key value storage with TTL for each record.
